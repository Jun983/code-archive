    함수¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 def로 함수를 만들고 호출하는 방법, 매개변수로 값을 넘기는 방법, return으로 결과를 돌려받는 방법만 익히면 충분합니다. 기본값, 가변 인수, 변수의 범위는 이런 것이 있다는 정도만 훑어보고, 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    함수는 자주 쓰는 코드를 이름을 붙여 묶어 둔 것이며, 이 문서에서는 함수의 정의와 호출, 매개변수와 인수, 반환값, 기본값, 가변 인수, 변수의 범위를 다룹니다.

    1. 함수란¶

    같은 코드를 여러 곳에서 써야 할 때 매번 복사하는 대신, 함수로 한 번 정의해 두고 이름으로 호출할 수 있습니다. 함수는 def 키워드로 정의하며, 조건문·반복문처럼 들여쓰기로 함수의 본문을 구분합니다.

    print("안녕하세요")

    용어 설명
    함수 이름을 붙여 묶어 둔 재사용 가능한 코드 묶음
    정의 def로 함수를 만드는 것 (정의만으로는 본문이 실행되지 않음)
    호출 함수 이름 뒤에 괄호를 붙여 본문을 실행하는 것
    • 함수는 호출될 때마다 본문을 처음부터 실행합니다.
    • 함수는 호출하기 전에 정의되어 있어야 합니다.
    • print(), input()처럼 Python이 미리 만들어 둔 함수를 내장 함수라고 합니다.

    정의와 호출¶

    def로 정의만 하면 아무 일도 일어나지 않고, 호출해야 본문이 실행됩니다. 이름 뒤에 괄호를 붙이지 않으면 호출이 아니라 함수 자체를 가리킬 뿐입니다.

    함수는 정의가 실행된 뒤에야 사용할 수 있으므로, 정의보다 먼저 호출하면 NameError가 발생합니다.

    2. 매개변수와 인수¶

    함수에 값을 전달하면 같은 코드로 다른 결과를 만들 수 있습니다. 정의할 때 괄호 안에 적는 변수가 매개변수이고, 호출할 때 넘기는 값이 인수입니다.

    전달 방식 의미
    위치 인수 매개변수 순서대로 값을 전달합니다. (add(3, 5))
    키워드 인수 이름=값 형태로 매개변수를 지정해 전달합니다. (add(b=5, a=3)) 
    1

    def add(a, b):
    print(a + b)

add(3, 5)
add(b=5, a=3)

    용어 설명
    매개변수 함수를 정의할 때 값을 받기 위해 적는 변수 (a, b)
    인수 함수를 호출할 때 실제로 넘기는 값 (3, 5)
    • 위치 인수는 순서가 중요하지만, 키워드 인수는 순서와 관계없이 이름으로 짝지어집니다.
    • 위치 인수와 키워드 인수를 섞을 때는 위치 인수를 먼저 써야 합니다.
    • 인수의 개수가 맞지 않으면 TypeError가 발생합니다.

    순서가 결과를 바꾸는 경우¶

    위치 인수는 순서대로 짝지어지므로, 순서를 바꾸면 결과도 달라집니다.

    인수 개수가 맞지 않는 경우¶

    3. 반환값¶

    함수는 return으로 계산 결과를 호출한 곳에 돌려줄 수 있습니다. 돌려받은 값은 변수에 저장하거나 다른 식에서 사용할 수 있습니다.

    1
2
3
4
5
6
    def add(a, b):
    return a + b

result = add(3, 5)
print(result)
print(add(1, 2) * 10)

    1
2
    8
30
    용어 설명
    반환값 return으로 호출한 곳에 돌려주는 값
    • return을 만나면 함수가 즉시 종료되며, 그 아래 코드는 실행되지 않습니다.
    • return이 없거나 값 없이 return만 쓰면 None이 반환됩니다.
    • 쉼표로 여러 값을 반환하면(return a, b) 하나의 튜플로 묶여 반환되며, 튜플은 자료구조에서 다룹니다.
    • print()는 화면에 출력할 뿐 값을 돌려주지 않으므로, 결과를 다시 사용하려면 return을 사용합니다.

    print와 return의 차이¶

    print()로 출력만 하는 함수는 값을 돌려주지 않으므로, 결과를 변수에 받으면 None이 들어 있습니다.

    • 계산 결과를 이어서 사용할 함수는 출력하지 않고 return으로 돌려주는 편이 재사용하기 좋습니다.
    • None은 타입에서 자세히 다룹니다.

    여러 값 반환¶

    쉼표로 값을 나열해 반환하면 호출하는 쪽에서 여러 변수로 나누어 받을 수 있습니다.

    def min_max(numbers):
    return min(numbers), max(numbers)

    • 여러 변수에 나누어 받는 방법은 변수에서 자세히 다룹니다.

    return으로 함수 일찍 끝내기¶

    조건에 맞으면 return으로 바로 끝내, 아래 코드를 실행하지 않을 수 있습니다.

    def check_age(age):

    • if는 조건문에서 자세히 다룹니다.

    4. 기본값¶

    매개변수에 기본값을 지정하면 호출할 때 해당 인수를 생략할 수 있습니다. 인수를 넘기면 넘긴 값이 기본값 대신 사용됩니다.

    1
2
3
4
5
6
    def greet(name, greeting="안녕하세요"):
    print(f"{greeting}, {name}")

greet("홍길동")
greet("홍길동", "반갑습니다")
greet("홍길동", greeting="어서 오세요")

    1
2
3
    안녕하세요, 홍길동
반갑습니다, 홍길동
어서 오세요, 홍길동
    용어 설명
    기본값 인수가 전달되지 않았을 때 매개변수가 가지는 값
    • 기본값이 있는 매개변수는 기본값이 없는 매개변수보다 뒤에 와야 합니다.
    • 기본값에 리스트처럼 변경 가능한 값([])을 쓰면 호출 간에 공유되어 의도치 않게 값이 쌓이므로 피해야 합니다.

    기본값의 순서 규칙¶

    기본값이 있는 매개변수 뒤에 기본값이 없는 매개변수를 두면 함수를 정의하는 시점에 SyntaxError가 발생합니다.

    1
2
    def greet(greeting="안녕하세요", name):
    print(f"{greeting}, {name}")

    1
2
3
4
      File "main.py", line 1
    def greet(greeting="안녕하세요", name):
                                     ^^^^
SyntaxError: parameter without a default follows parameter with a default
    • name처럼 반드시 받아야 하는 매개변수를 앞에 두고, 기본값이 있는 매개변수를 뒤에 둡니다.
    • 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.

    변경 가능한 기본값의 문제¶

    기본값은 함수를 정의할 때 한 번만 만들어지므로, 리스트를 기본값으로 쓰면 호출 간에 같은 리스트를 계속 사용합니다.

    1
2
3
4
5
6
    def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("a"))
print(add_item("b"))

    1
2
    ['a']
['a', 'b']
    • 두 번째 호출은 새 리스트가 아니라 첫 번째 호출에서 쓴 리스트에 이어 붙입니다.
    • 기본값을 None으로 두고 함수 안에서 새 리스트를 만들면 이 문제를 피할 수 있습니다.
    1
2
3
4
5
6

8
    def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

print(add_item("a"))
print(add_item("b"))

    1
2
    ['a']
['b']
    • list는 자료구조에서, is None 비교는 조건문에서 자세히 다룹니다.

    5. 가변 인수¶

    인수의 개수를 미리 정할 수 없을 때는 매개변수 앞에 * 또는 **를 붙여 개수에 관계없이 받을 수 있습니다.

    형태 의미
    *args 나머지 위치 인수를 모두 튜플로 받습니다.
    **kwargs 나머지 키워드 인수를 모두 딕셔너리로 받습니다.

    def total(*args):
    return sum(args)

def show(**kwargs):
    for key, value in kwargs.items():
        print(key, value)

    용어 설명
    가변 인수 개수가 정해지지 않은 인수
    args / kwargs 가변 인수를 받는 매개변수의 관례적인 이름 (arguments, keyword arguments)
    • *와 **가 문법이고 args, kwargs는 관례적인 이름이므로 다른 이름을 써도 됩니다.
    • 일반 매개변수, *args, **kwargs 순서로 써야 합니다.
    • 딕셔너리는 자료구조에서 다룹니다.

    받은 값의 형태¶

    *args는 튜플, **kwargs는 딕셔너리로 전달되므로, 인수를 넘기지 않으면 빈 튜플과 빈 딕셔너리가 됩니다.

    1

    def info(*args, **kwargs):
    print(args)
    print(kwargs)

info(1, 2, name="홍길동")
info()

    • 반복문으로 args의 값을 하나씩 꺼내 사용할 수 있으며, 반복문은 반복문에서 자세히 다룹니다.

    일반 매개변수와 함께 쓰기¶

    고정된 매개변수를 먼저 받고, 나머지를 가변 인수로 받을 수 있습니다.

    def print_all(title, *items):
    print(title)
    for item in items:

    호출할 때 풀어서 넘기기¶

    호출하는 쪽에서 리스트나 딕셔너리 앞에 *, **를 붙이면 요소를 하나씩 풀어 인수로 넘깁니다.

    def add(a, b):
    return a + b

numbers = [3, 5]
values = {"a": 1, "b": 2}

print(add(*numbers))

2
    8

    6. 변수의 범위¶

    함수 안에서 만든 변수는 그 함수 안에서만 사용할 수 있습니다. 매개변수도 함수 안에서만 존재합니다.

    def calc():
    result = 10

    용어 설명
    지역 변수 함수 안에서 만들어져 그 함수 안에서만 사용할 수 있는 변수
    전역 변수 함수 밖에서 만들어져 파일 어디에서나 읽을 수 있는 변수
    • 함수 안의 변수는 함수가 끝나면 사라지므로, 값을 밖에서 쓰려면 return으로 돌려받습니다.
    • 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.

    전역 변수와 같은 이름¶

    함수 안에서 전역 변수와 같은 이름에 대입하면 값을 바꾸는 것이 아니라 새로운 지역 변수가 만들어집니다.

    1
2
3
4
5
6
7
8
    count = 0

def increase():
    count = 100
    print("함수 안:", count)

increase()
print("함수 밖:", count)

    1
2
    함수 안: 100
함수 밖: 0
    • 함수 안에서도 전역 변수의 값을 읽는 것은 가능합니다.
    • 함수 밖의 값을 함수 안에서 바꾸고 싶다면 return으로 새 값을 돌려받아 대입하는 방식이 가장 명확합니다.
    • 변수에 값을 대입하는 방법은 변수에서 자세히 다룹니다.
