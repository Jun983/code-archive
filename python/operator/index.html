    연산자¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 산술 연산자(+, -, *, /), 비교 연산자(==, <, >), 논리 연산자(and, or, not)와 =와 ==의 차이만 익히면 충분합니다. 우선순위 표를 외울 필요는 없으며, 헷갈리는 식은 괄호로 묶으면 됩니다. 나머지는 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    연산자는 값을 계산하거나 비교·조합할 때 사용하는 기호이며, 이 문서에서는 산술·문자열·대입·비교·논리·멤버십 연산자와 연산자 우선순위를 다룹니다.

    1. 연산자란¶

    연산자는 하나 이상의 값을 받아 새로운 값을 만들어 내는 기호나 키워드입니다. 연산 대상이 되는 값은 피연산자라고 하며, 3 + 4에서 +는 연산자, 3과 4는 피연산자입니다.

    1
2
3
    print(3 + 4)
print(3 < 4)
print("a" in "abc")

3
    7
True
True
    용어 설명
    연산자 피연산자를 계산하거나 비교해 새로운 값을 만드는 기호 또는 키워드
    피연산자 연산자가 처리하는 대상 값
    단항 연산자 피연산자가 하나인 연산자 (not, -x)
    이항 연산자 피연산자가 둘인 연산자 (+, ==, and)
    • 연산 결과는 값이므로 변수에 저장하거나 print()로 바로 출력할 수 있습니다.
    • and, or, not, in처럼 기호가 아닌 영단어로 된 연산자도 있습니다.

    연산자의 종류¶

    이 문서에서 다루는 연산자는 용도에 따라 다음과 같이 나뉩니다.

    종류 연산자 결과
    산술 +, -, *, /, //, %, ** 숫자
    문자열 +, * 문자열
    대입 =, +=, -= 등 변수에 값 저장
    비교 ==, !=, <, >, <=, >= bool
    논리 and, or, not bool
    멤버십 in, not in bool
    • 같은 기호라도 피연산자의 타입에 따라 동작이 달라집니다. 예를 들어 +는 숫자에서는 덧셈, 문자열에서는 이어 붙이기입니다.

    2. 산술 연산자¶

    숫자를 계산해 새로운 숫자를 반환합니다.

    연산자 의미
    + 왼쪽 값과 오른쪽 값을 더한 값을 반환합니다.
    - 왼쪽 값에서 오른쪽 값을 뺀 값을 반환합니다.
    * 왼쪽 값과 오른쪽 값을 곱한 값을 반환합니다.
    / 왼쪽 값을 오른쪽 값으로 나눈 값을 float로 반환합니다.
    // 나눗셈의 몫을 정수로 반환합니다 (버림 나눗셈).
    % 나눗셈의 나머지를 반환합니다.
    ** 거듭제곱 값을 반환합니다.

    버림 나눗셈 나눗셈 결과를 소수점 이하를 버리고 정수로 만드는 연산 (//)
    • /는 정수끼리 나눠도 항상 float를 반환합니다. 정수 몫이 필요하면 //를 사용합니다.
    • //는 0에 가까운 쪽이 아니라 음의 무한대 쪽으로 내림하므로 -7 // 2는 -4입니다.
    • %는 홀수·짝수 판별(n % 2)처럼 나머지가 필요할 때 자주 사용합니다.
    • 숫자 간 +는 덧셈이지만, 문자열에 사용하면 이어 붙이기가 됩니다. 문자열에서의 동작은 다음 절에서 자세히 다룹니다.

    3. 문자열 연산자¶

    +와 *는 문자열에도 사용할 수 있으며, 숫자가 아니라 새로운 문자열을 반환합니다.

    연산자 의미
    + 두 문자열을 이어 붙인 새 문자열을 반환합니다.
    * 문자열을 정수 횟수만큼 반복한 새 문자열을 반환합니다. 
    1
2
3
4
5
6
    first = "Hello"
second = "Python"

print(first + " " + second)
print(first * 3)
print("-" * 10)

    1
2
3
    Hello Python
HelloHelloHello
----------
    용어 설명
    연결 문자열을 +로 이어 붙이는 것
    반복 문자열을 *로 여러 번 이어 붙이는 것
    • +는 양쪽이 모두 문자열이어야 하며, "나이: " + 25처럼 숫자와 섞으면 TypeError가 발생합니다. 숫자는 str()로 변환해야 하며, 이는 형변환에서 자세히 다룹니다.
    • *의 반대편 피연산자는 정수여야 합니다.
    • 문자열은 변경할 수 없으므로 연산할 때마다 원본은 그대로 두고 새 문자열이 만들어집니다.
    • 비교(==)와 멤버십(in)도 문자열에 사용할 수 있으며, 각각 이후 절에서 자세히 다룹니다.

    숫자 문자열의 연산¶

    숫자 모양의 문자열도 문자열이므로 +는 이어 붙이기, *는 반복이 됩니다.

print(int("3") + int("4"))

    • 문자열을 만들고 다루는 방법은 문자열에서 자세히 다룹니다.

    4. 대입 연산자¶

    변수에 값을 할당합니다. = 외의 연산자는 산술 연산과 대입을 한 번에 수행하는 복합 대입 연산자입니다.

    연산자 의미
    = 오른쪽 값을 왼쪽 변수에 할당합니다.
    += 변수에 오른쪽 값을 더한 뒤 할당합니다.
    -= 변수에서 오른쪽 값을 뺀 뒤 할당합니다.
    *= 변수에 오른쪽 값을 곱한 뒤 할당합니다.
    /= 변수를 오른쪽 값으로 나눈 뒤 할당합니다.
    //= 변수를 오른쪽 값으로 나눈 몫을 할당합니다.
    %= 변수를 오른쪽 값으로 나눈 나머지를 할당합니다.

    • count += 5는 count = count + 5와 같은 의미입니다.
    • /=를 사용하면 결과가 float가 되므로 변수의 타입이 바뀝니다.
    • 변수를 만들고 값을 대입하는 방법은 변수에서 자세히 다룹니다.

    • 반복문에서 값을 누적하는 방법은 반복문에서 자세히 다룹니다.

    5. 비교 연산자¶

    두 값을 비교해 bool을 반환합니다.

    연산자 의미
    == 두 값이 같으면 True를 반환합니다.
    != 두 값이 다르면 True를 반환합니다.
    < 왼쪽 값이 오른쪽 값보다 작으면 True를 반환합니다.
    > 왼쪽 값이 오른쪽 값보다 크면 True를 반환합니다.
    <= 왼쪽 값이 오른쪽 값보다 작거나 같으면 True를 반환합니다.
    >= 왼쪽 값이 오른쪽 값보다 크거나 같으면 True를 반환합니다. 
    1
2
3
4
5

    a = 10
b = 3

print(a == b)
print(a != b)
print(a < b)
print(a > b)
print(1 < b < 5)

    용어 설명
    연쇄 비교 비교 연산자를 이어 붙여 1 < b < 5처럼 범위를 한 번에 검사하는 문법
    • =는 대입, ==는 비교이므로 혼동하지 않아야 합니다.
    • 문자열도 ==로 값(내용) 비교가 바로 됩니다.
    • 1 < b < 5는 1 < b and b < 5와 같은 의미입니다.

    타입이 다른 값의 비교¶

    ==는 타입이 달라도 오류 없이 False를 반환하지만, 대소 비교는 TypeError가 발생합니다.

    1
2
3
    print(1 == 1.0)
print(1 == "1")
print(1 < "2")

  File "main.py", line 3, in <module>
    print(1 < "2")
TypeError: '<' not supported between instances of 'int' and 'str'
    • int와 float는 값이 같으면 ==가 True입니다.
    • 모양이 같아도 1과 "1"은 서로 다른 값입니다.
    • 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
    • 문자열을 숫자로 바꿔 비교하는 방법은 형변환에서 자세히 다룹니다.

    문자열 비교¶

    문자열은 ==로 내용을 비교하고, <, >는 사전 순서로 비교합니다.

    • 대소문자를 구분하지 않고 비교하려면 lower()로 통일한 뒤 비교하며, 문자열에서 자세히 다룹니다.

    실수의 비교¶

    float는 근사값으로 저장되므로 계산 결과를 ==로 비교하면 예상과 다를 수 있습니다.

    6. 논리 연산자¶

    not True는 False로, False는 True로 반환합니다.

    용어 설명
    단락 평가 왼쪽 값만으로 결과가 정해지면 오른쪽 값을 평가하지 않는 동작
    • 논리 연산에는 기호 대신 and, or, not 키워드를 사용합니다.
    • and는 왼쪽이 False이면, or는 왼쪽이 True이면 오른쪽을 평가하지 않습니다.
    • 조건문에서 여러 조건을 조합하는 방법은 조건문에서 자세히 다룹니다.

    진리표¶

    and와 or는 두 값의 조합에 따라 결과가 정해집니다.

    False False False False

    and와 or는 피연산자가 bool이 아니면 True/False가 아니라 피연산자 중 하나를 그대로 반환합니다.

    • and는 왼쪽이 거짓으로 취급되면 왼쪽을, 아니면 오른쪽을 반환합니다.

    8. 연산자 우선순위¶

    한 식에 연산자가 여러 개 있으면 우선순위가 높은 연산자부터 계산합니다.

    순위 연산자
    1 (높음) **
    2 *, /, //, %
    3 +, -
    4 ==, !=, <, >, <=, >=, in, not in
    5 not
    6 and
    7 (낮음) or 
    1
2
3
4
    print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(True or False and False)

    1
2
3
4
    14
20
512
True
    • 괄호 ()로 묶은 부분이 가장 먼저 계산됩니다.
    • **는 오른쪽부터 계산하므로 2 ** 3 ** 2는 2 ** 9입니다.
    • 우선순위가 헷갈리는 식은 괄호로 의도를 명확히 드러내는 편이 좋습니다.

    같은 순위의 계산 순서¶

    우선순위가 같은 연산자는 왼쪽에서 오른쪽으로 계산합니다. **만 예외로 오른쪽부터 계산합니다.

    1
2
    print(10 - 3 - 2)
print(100 / 10 * 2)

    1
2
    5
20.0
    • 10 - 3 - 2는 (10 - 3) - 2로 계산되어 5입니다.
    • 100 / 10 * 2는 (100 / 10) * 2이므로 /의 결과인 float가 이어져 20.0입니다.

    부호와 비교, 논리의 우선순위¶

    단항 -는 **보다 낮고 *보다 높으며, not은 비교보다 낮습니다.

    1
2
3
    print(-2 ** 2)
print((-2) ** 2)
print(not 1 == 2)

3
    -4

True
    • -2 ** 2는 -(2 ** 2)로 계산되므로 -4입니다. 음수를 제곱하려면 괄호로 묶습니다.
    • not 1 == 2는 1 == 2를 먼저 계산한 뒤 not을 적용하므로 not (1 == 2)와 같습니다.
