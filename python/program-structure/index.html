    프로그램 구조¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 print() 한 줄을 파일에 작성해 실행해 보고, 코드가 위에서 아래로 실행된다는 점과 들여쓰기가 문법이라는 점만 익히면 충분합니다. if, 함수처럼 아직 배우지 않은 문법이 예제에 나와도 지금 이해하지 않아도 괜찮으며, 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    Python 프로그램은 .py 파일에 작성한 코드를 위에서 아래로 순서대로 실행하는 구조이며, 이 문서에서는 첫 프로그램을 통해 실행 방식과 코드를 구성하는 기본 규칙을 다룹니다.

    1. 첫 프로그램¶

    가장 간단한 Python 프로그램은 print() 한 줄입니다. 별도의 클래스나 main 함수 없이도 하나의 프로그램이 됩니다.

    1
2
    # hello.py
print("Hello, World!")

    터미널에서 python 명령어 뒤에 파일명을 입력하면 실행됩니다.

    1
    python hello.py

    1
    Hello, World!
    용어 설명
    스크립트 위에서 아래로 순서대로 실행되는 Python 파일
    실행 터미널에서 python 파일명을 입력해 인터프리터가 파일을 처리하는 것
    • 파일 확장자는 .py를 사용합니다.
    • 파일을 저장한 폴더에서 명령어를 실행하거나, python 경로/hello.py처럼 경로를 함께 입력합니다.
    • 운영체제에 따라 python 대신 python3 명령어를 사용해야 할 수 있습니다.
    • 파일을 만들지 않고 python만 입력하면 한 줄씩 입력하고 바로 결과를 확인하는 대화형 모드로 들어갑니다. 종료할 때는 exit()를 입력합니다.
    • 설치와 프로젝트 생성 및 실행은 개발환경 설정에서 자세히 다룹니다.

    2. 실행 순서¶

    Python은 진입점이 따로 없으며, 파일의 첫 줄부터 마지막 줄까지 한 줄씩 순서대로 실행합니다.

    1
2
3
    print("1번")
print("2번")
print("3번")

    1
2
3
    1번
2번
3번
    • 코드의 순서가 곧 실행 순서입니다.
    • 빈 줄은 실행에 영향을 주지 않으므로, 코드를 구분해서 읽기 쉽게 만드는 용도로 사용합니다.
    • 실행 중 오류가 발생하면 그 줄에서 멈추고, 이후 코드는 실행되지 않습니다.

    오류가 발생하는 경우¶

    오류가 발생하기 전의 코드는 이미 실행된 상태입니다.

    1
2
3
    print("시작")
print(value)
print("끝")

    1
2
3
4
5
    시작
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(value)
NameError: name 'value' is not defined
    • 시작은 정상적으로 출력되고, 오류가 발생한 2번째 줄에서 멈추므로 끝은 출력되지 않습니다.
    • value처럼 아직 만들지 않은 이름을 사용하면 NameError가 발생합니다. 이름은 사용하는 줄보다 위에서 먼저 만들어져 있어야 합니다.
    • 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
    • 이름을 만드는 방법은 변수에서 자세히 다룹니다.

    함수와 실행 순서¶

    함수는 정의하는 시점에는 실행되지 않고, 호출하는 시점에 실행됩니다. 따라서 정의가 호출보다 위에 있어야 합니다.

    1
2
3
4
5
    def greet():
    print("안녕하세요")

print("시작")
greet()

    1
2
    시작
안녕하세요
    • def 블록은 읽기만 하고 넘어가며, 안의 코드는 greet()를 호출하는 줄에서 실행됩니다.
    • greet() 호출을 def보다 위에 쓰면 아직 이름이 없으므로 NameError가 발생합니다.
    • 함수를 정의하고 호출하는 방법은 함수에서 자세히 다룹니다.

    3. 주석¶

    # 뒤에 오는 내용은 실행되지 않으며, 코드에 대한 설명을 남길 때 사용합니다.

    1
2
    # 한 줄 주석
print("Hello")  # 코드 뒤에도 작성할 수 있습니다

    1
    Hello
    • 주석은 해당 줄의 끝까지만 적용됩니다.
    • 여러 줄 주석 문법은 따로 없으며, 줄마다 #을 붙입니다.
    • 코드 뒤에 주석을 쓸 때는 코드와 # 사이에 공백 2칸을 두는 것이 관례입니다.

    주석 처리¶

    실행하고 싶지 않은 코드 앞에 #을 붙이면 지우지 않고 잠시 실행에서 제외할 수 있습니다.

    1
2
3
    print("A")
# print("B")
print("C")

    1
2
    A
C

    문자열 안의¶

    따옴표 안에 있는 #은 주석이 아니라 문자열의 일부입니다.

    1
    print("# 은 주석이 아닙니다")

    1
    # 은 주석이 아닙니다

    좋은 주석¶

    • 코드를 그대로 설명하는 주석보다 코드만으로는 알기 어려운 이유와 의도를 적습니다.
    • 코드가 바뀌었는데 주석이 그대로 남아 있으면 오히려 혼란을 주므로, 코드를 수정할 때 주석도 함께 확인합니다.
    • 문자열 출력과 따옴표 규칙은 출력에서 자세히 다룹니다.

    4. 들여쓰기¶

    Python은 중괄호({}) 대신 들여쓰기로 코드 블록을 구분합니다. 같은 블록 안의 코드는 들여쓰기 칸 수가 같아야 합니다.

    1
2
3
4
    if True:
    print("블록 안")
    print("같은 블록")
print("블록 밖")

    1
2
3
    블록 안
같은 블록
블록 밖
    용어 설명
    블록 하나로 묶여 함께 실행되는 코드의 덩어리
    들여쓰기 줄의 앞쪽에 공백을 넣어 블록의 범위를 나타내는 것
    • 블록을 시작하는 줄은 :(콜론)으로 끝나며, 다음 줄부터 들여쓰기한 코드가 그 블록에 속합니다.
    • 들여쓰기는 공백 4칸을 사용하는 것이 관례입니다.
    • 들여쓰기가 맞지 않으면 IndentationError가 발생하고, 실행은 시작되지 않습니다.
    • if 문법은 조건문에서 자세히 다룹니다.

    중첩 블록¶

    블록 안에 또 다른 블록이 있으면 들여쓰기가 한 단계씩 깊어집니다.

    1
2
3
4
5
    if True:
    print("바깥 블록")
    if True:
        print("안쪽 블록")
print("블록 밖")

    1
2
3
    바깥 블록
안쪽 블록
블록 밖

    들여쓰기 오류¶

    블록 안의 줄은 들여쓰기 칸 수가 서로 같아야 합니다.

    1
2
3
    if True:
    print("4칸")
      print("6칸")

    1
2
3
      File "main.py", line 3
    print("6칸")
IndentationError: unexpected indent
    • 블록을 시작하는 : 뒤에 들여쓴 코드가 없는 경우에도 IndentationError가 발생합니다.
    • 공백과 탭을 섞어서 쓰면 TabError가 발생할 수 있으므로, 에디터에서 탭 키가 공백 4칸으로 입력되도록 설정합니다.
    • 오류 메시지의 줄 번호와 표시 형식은 Python 버전에 따라 조금씩 다를 수 있습니다.

    5. 문장과 줄¶

    Python은 한 줄에 하나의 문장을 작성하는 것이 기본입니다. 문장 끝에 세미콜론(;)을 붙이지 않습니다.

    1
2
    print("첫 번째 문장입니다.")
print("두 번째 문장입니다.")

    1
2
    첫 번째 문장입니다.
두 번째 문장입니다.
    용어 설명
    문장 인터프리터가 하나의 명령으로 처리하는 코드의 단위
    • 세미콜론으로 한 줄에 여러 문장을 쓸 수도 있지만, 가독성이 떨어지므로 권장하지 않습니다.

    줄 이어쓰기¶

    문장이 길면 괄호 안에서는 줄을 바꿔도 하나의 문장으로 처리됩니다.

    1
2
3
    total = (1 + 2
         + 3 + 4)
print(total)

    1
    10

    괄호 밖에서 줄을 이으려면 줄 끝에 역슬래시(\)를 붙입니다.

    1
2
3
    total = 1 + 2 \
        + 3 + 4
print(total)

    1
    10
    • 역슬래시 바로 뒤에는 공백을 포함해 아무것도 오면 안 됩니다. 공백이 있으면 SyntaxError가 발생합니다.
    • 괄호 방식이 실수하기 쉬운 역슬래시보다 권장됩니다.
    • 줄 이어쓰기에서 쓰인 +와 같은 연산자는 연산자에서 자세히 다룹니다.
    • 값을 화면에 출력하는 방법은 출력에서 자세히 다룹니다.
