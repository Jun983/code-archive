    출력¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 print()로 값을 화면에 출력하는 기본 사용법만 익히면 충분합니다. 언패킹, file, flush처럼 낯선 내용은 지금 이해하지 않아도 괜찮으며, 변수와 함수 등 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    Python의 기본적인 출력 수단은 print() 함수이며, 이 문서에서는 값을 출력하는 방법과 출력 형식을 조절하는 방법을 다룹니다.

    1. print() 개요¶

    print()는 괄호 안의 값을 화면에 출력하는 내장 함수이며, 프로그램의 실행 결과를 확인하는 가장 기본적인 수단입니다.

    1
2
3
4
5
    print("Hello, World!")
print(42)
print(3.14)
print(True)
print(None)

    1
2
3
4
5
    Hello, World!
42
3.14
True
None
    용어 설명
    내장 함수 import 없이 어디서나 호출할 수 있도록 Python에 기본 포함된 함수

    함수 구조¶

    print()는 출력할 값과 출력 방식을 조절하는 옵션을 함께 받을 수 있습니다.

    1
    print(*values, sep=" ", end="\n", file=sys.stdout, flush=False)
    인자 설명 기본값
    *values 출력할 값. 개수 제한 없이 여러 개를 쉼표로 나열할 수 있습니다. (없음)
    sep 값과 값 사이에 넣을 구분자 공백 한 칸 (" ")
    end 출력 맨 끝에 붙일 문자열 줄 바꿈 ("\n")
    file 출력을 보낼 대상 화면 (sys.stdout)
    flush 출력을 버퍼에 두지 않고 즉시 내보낼지 여부 False

    sep, end, file, flush는 이름을 붙여서(sep="-") 전달해야 합니다. 이름 없이 넘기면 출력할 값으로 취급됩니다.

    각 옵션은 아래 섹션에서 차례로 자세히 다룹니다.

    반환값¶

    print()는 화면에 출력하는 것이 역할이고, 반환하는 값은 항상 None입니다.

    1
2
    result = print("hi")
print(result)

    1
2
    hi
None

    출력한 내용을 변수에 담아 쓸 수는 없으므로, 값을 계산하는 용도가 아니라 보여주는 용도로만 사용합니다.

    • 예제의 result = ...처럼 값을 변수에 담는 방법은 변수에서 자세히 다룹니다.

    2. 출력 규칙¶

    • 문자열은 큰따옴표(")와 작은따옴표(') 중 어느 것을 써도 동일하게 동작합니다.
    • 숫자, True, None은 따옴표 없이 그대로 출력합니다.
    • 출력이 끝나면 줄 바꿈이 자동으로 추가되므로, 여러 번 호출하면 결과가 줄마다 나뉘어 출력됩니다.
    • 값을 넘기지 않고 print()만 호출하면 빈 줄이 출력됩니다.

    따옴표 선택¶

    문자열 안에 따옴표가 들어가면, 바깥을 다른 종류의 따옴표로 감싸서 이스케이프 없이 그대로 쓸 수 있습니다.

    1
2
    print('He said "Hi"')
print("It's fine")

    1
2
    He said "Hi"
It's fine

    여러 줄 문자열¶

    삼중 따옴표(""" 또는 ''')로 감싸면 줄 바꿈을 포함한 여러 줄을 하나의 문자열로 쓸 수 있습니다.

    1
2
3
    print("""첫째 줄
둘째 줄
셋째 줄""")

    1
2
3
    첫째 줄
둘째 줄
셋째 줄
    • 따옴표 안의 줄 바꿈과 들여쓰기가 그대로 문자열에 포함됩니다.
    • 시작 따옴표 바로 뒤에서 줄을 바꾸면 첫 줄이 빈 줄로 출력됩니다.

    3. print() 동작¶

    print()는 받은 값을 그대로 출력하지 않고, 각 값을 str()로 문자열로 변환한 뒤 출력합니다.

    예시: print(42)는 정수 42를 전달받지만, 내부에서 str(42)를 호출한 결과인 "42"를 출력합니다.

    용어 설명
    str() 값을 사람이 읽기 좋은 문자열로 바꾸는 내장 함수
    repr() 값을 Python 코드에 가까운 형태의 문자열로 바꾸는 내장 함수. 문자열은 따옴표가 붙습니다.

    변환 결과¶

    값의 타입이 달라도 출력되는 것은 모두 문자열입니다. 그래서 화면에서는 문자열 "1"과 정수 1이 똑같이 보입니다.

    1
2
3
4
    print(1)
print("1")
print(None)
print(True)

    1
2
3
4
    1
1
None
True
    • None과 True도 str()을 거쳐 "None", "True"라는 글자로 출력됩니다.
    • 화면 출력만으로는 값의 타입을 구분할 수 없습니다.
    • 값의 타입을 확인하는 방법은 타입에서 자세히 다룹니다.

    리스트 안의 문자열¶

    리스트처럼 여러 값을 담는 자료구조를 출력하면, 담긴 값은 str()이 아니라 repr()로 변환되어 출력됩니다.

    1
2
    print("a")
print(["a", "b"])

    1
2
    a
['a', 'b']
    • 문자열 "a"를 직접 출력할 때는 따옴표가 없지만, 리스트 안의 문자열에는 따옴표가 붙습니다.
    • 자료구조 안의 값이 문자열인지 숫자인지 화면에서 구분할 수 있도록 하기 위한 동작입니다.
    • 리스트를 비롯한 자료구조는 자료구조에서 자세히 다룹니다.

    4. 이스케이프 문자¶

    문자열 안에서 역슬래시(\)로 시작하는 문자는 줄 바꿈이나 탭 같은 특수한 문자를 나타냅니다.

    1
2
3
4
5
    print("Hello\nWorld")
print("Name\tAge")
print("He said \"Hi\"")
print("C:\\new\\folder")
print("\uD55C\uAE00")

    1
2
3
4
5
6
    Hello
World
Name    Age
He said "Hi"
C:\new\folder
한글
    표기 의미
    \n 줄 바꿈
    \t 탭
    \r 줄의 맨 앞으로 커서 이동 (캐리지 리턴)
    \", \' 따옴표 문자 그대로
    \\ 역슬래시 문자 그대로
    \uXXXX 16진수 4자리에 해당하는 유니코드 문자 (\uD55C는 한)
    • \r은 커서를 줄 맨 앞으로 옮기므로, 같은 줄에 이어서 출력한 내용이 앞의 내용을 덮어씁니다. 진행률처럼 한 줄을 계속 갱신할 때 사용합니다.
    • 윈도우 경로처럼 역슬래시가 많은 문자열은 \\로 일일이 쓰는 대신, 이스케이프를 해석하지 않는 raw string(r"C:\new\folder")을 사용할 수 있습니다.
    • raw string은 문자열에서 자세히 다룹니다.

    잘못된 이스케이프¶

    정의되지 않은 조합(\d 등)은 오류 없이 역슬래시가 그대로 출력되지만, 실행 시 경고가 표시됩니다.

    1
    print("\d")

    1
2
    <stdin>:1: SyntaxWarning: invalid escape sequence '\d'
\d
    • 의도하지 않은 이스케이프일 수 있으므로 \\d로 쓰거나 raw string을 사용합니다.
    • 경고 메시지의 형식은 Python 버전에 따라 다를 수 있습니다.

    5. 여러 값 출력¶

    여러 값을 쉼표로 나열하면 공백으로 구분해 한 줄에 출력합니다. 값의 종류가 달라도 각 값을 str()로 변환해 이어 붙이므로 동일하게 동작합니다.

    1
2
3
    print(1, 2, 3)
print("Age:", 20)
print("Pi:", 3.14, True, None)

    1
2
3
    1 2 3
Age: 20
Pi: 3.14 True None

    쉼표와 + 연산자¶

    문자열끼리는 +로 이어 붙일 수 있지만, +는 str() 변환을 해주지 않으므로 문자열과 숫자를 함께 쓰면 오류가 발생합니다.

    1
2
    print("Age:", 20)
print("Age:" + 20)

    1
2
3
4
5
    Age: 20
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print("Age:" + 20)
TypeError: can only concatenate str (not "int") to str
    • 쉼표는 print()가 값마다 변환하고 공백으로 구분해주지만, +는 print()에 도달하기 전에 먼저 계산되어 오류가 납니다.
    • 숫자를 +로 이어 붙이려면 str(20)처럼 직접 변환해야 합니다.
    • 값을 다른 타입으로 변환하는 방법은 형변환에서 자세히 다룹니다.

    언패킹¶

    값 앞에 *를 붙이면 리스트의 원소를 하나씩 풀어서 각각 별도의 값으로 전달합니다.

    1
2
3
    numbers = [1, 2, 3]
print(numbers)
print(*numbers)

    1
2
    [1, 2, 3]
1 2 3
    • print(numbers)는 리스트 하나를 출력하므로 대괄호가 함께 나옵니다.
    • print(*numbers)는 print(1, 2, 3)과 같이 동작해 대괄호 없이 원소만 출력합니다.

    6. 구분자 변경¶

    sep에 문자열을 넘기면 값 사이에 들어가는 구분자를 바꿀 수 있습니다. 기본값은 공백 한 칸(" ")입니다.

    1
2
3
    print(2025, 10, 24, sep="-")
print("a", "b", "c", sep="")
print("a", "b", "c", sep="\n")

    1
2
3
4
5
    2025-10-24
abc
a
b
c
    • sep는 값과 값 사이에만 들어가며, 마지막 값 뒤에는 붙지 않습니다.
    • 값이 하나뿐이면 sep를 지정해도 아무 영향이 없습니다.
    • 언패킹과 함께 쓰면 리스트 원소를 원하는 구분자로 이어서 출력할 수 있습니다. 예: print(*[1, 2, 3], sep=", ")는 1, 2, 3을 출력합니다.

    7. 줄 바꿈 제어¶

    print()는 출력 끝에 줄 바꿈(\n)을 자동으로 붙입니다. end에 문자열을 넘기면 이 기본 동작을 바꿀 수 있으며, 빈 문자열("")을 넘기면 다음 출력이 줄 바꿈 없이 이어집니다.

    1
2
3
4
5
    print("Hello", end="")
print(", World!")
print("A", end=" ")
print("B", end=" ")
print("C")

    1
2
    Hello, World!
A B C

    다른 끝 문자¶

    end에는 공백이나 빈 문자열뿐 아니라 어떤 문자열도 넘길 수 있습니다.

    1
2
3
4
5
    print("사과", end=", ")
print("배", end=", ")
print("포도")
print("끝", end="\n\n")
print("빈 줄 뒤에 출력")

    1
2
3
4
    사과, 배, 포도
끝

빈 줄 뒤에 출력
    • end="\n\n"은 줄 바꿈을 두 번 출력하므로 다음 출력 앞에 빈 줄이 한 줄 생깁니다.

    sep와 end 함께 사용¶

    두 옵션은 서로 독립적이어서 함께 지정할 수 있습니다. sep는 값 사이, end는 맨 끝에 적용됩니다.

    1
2
    print(1, 2, 3, sep="-", end="!\n")
print("다음 줄")

    1
2
    1-2-3!
다음 줄

    8. 출력 대상과 버퍼¶

    file¶

    file에 출력 대상을 넘기면 화면 대신 다른 곳으로 출력할 수 있습니다. 오류 메시지는 일반 출력과 구분해 표준 오류(sys.stderr)로 보내는 것이 일반적입니다.

    1
2
3
4
    import sys

print("정상 출력")
print("오류 발생", file=sys.stderr)

    1
2
    정상 출력
오류 발생
    • 터미널에서는 두 출력이 모두 화면에 보이지만, 실제로는 서로 다른 통로로 나갑니다. 그래서 python main.py > out.txt처럼 파일로 저장하면 정상 출력만 파일에 저장되고 오류 발생은 화면에 남습니다.
    • sys는 Python 실행 환경에 관한 기능을 모아둔 표준 모듈이며, import로 불러와 사용합니다.
    • import와 모듈은 모듈과 패키지에서 자세히 다룹니다.

    flush¶

    출력은 곧바로 화면에 나가지 않고 버퍼라는 임시 공간에 모였다가 한꺼번에 나갈 수 있습니다. 줄 바꿈 없이 출력하는 경우에는 버퍼가 비워지지 않아 화면에 늦게 나타날 수 있는데, flush=True를 지정하면 즉시 내보냅니다.

    1
2
3
4
5
    import time

print("처리 중...", end="", flush=True)
time.sleep(2)
print("완료")

    1
    처리 중...완료
    • flush=True가 없으면 처리 중...이 2초 뒤 완료와 함께 나타날 수 있습니다.
    • 기본값이 False인 이유는 출력할 때마다 비우면 속도가 느려지기 때문입니다.
