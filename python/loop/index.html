    반복문¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 for i in range(n):으로 정해진 횟수만큼 반복하는 방법과, 조건이 True인 동안 반복하는 while의 기본 형태만 익히면 충분합니다. 중첩 반복문과 for ... else는 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    반복문은 같은 코드를 여러 번 실행하는 문법이며, 이 문서에서는 for, while, 반복 흐름을 제어하는 break와 continue를 다룹니다.

    1. 반복문이란¶

    같은 작업을 여러 번 해야 할 때 코드를 그대로 복사하는 대신 반복문을 사용하면 한 번만 작성해도 원하는 횟수만큼 실행할 수 있습니다. 반복문도 조건문처럼 들여쓰기로 반복할 블록을 구분합니다.

    1
2
3
4
    for i in range(3):
    print("안녕")

print("종료")

    1
2
3
4
    안녕
안녕
안녕
종료
    용어 설명
    반복문 블록을 여러 번 반복 실행하는 문장
    반복(iteration) 블록이 한 번 실행되는 것
    루프 반복문이 반복되는 흐름 (반복문과 같은 의미로 쓰임)
    • 반복 횟수가 정해져 있거나 원소를 차례로 꺼낼 때는 for, 조건이 만족되는 동안 반복할 때는 while을 사용합니다.
    • 들여쓰지 않은 print("종료")는 반복이 모두 끝난 뒤 한 번만 실행됩니다.
    • 반복문 끝의 콜론(:)과 들여쓰기 규칙, 이를 어겼을 때의 오류는 조건문과 같습니다.

    반복하지 않는 경우¶

    반복할 대상이 없으면 블록은 한 번도 실행되지 않고, 오류 없이 다음 코드로 넘어갑니다.

    1
2
3
4
    for i in range(0):
    print("실행되지 않음")

print("끝")

    1
    끝
    • 반복 횟수가 0이어도 오류가 아니며, 블록만 건너뜁니다.

    2. for¶

    시퀀스(문자열, 리스트, range() 등)의 원소를 순서대로 하나씩 꺼내며 블록을 실행합니다. 초기화·조건·증감식을 직접 쓰지 않고, 꺼낼 원소가 없으면 자동으로 끝납니다.

    형태 의미
    for 변수 in 시퀀스: 시퀀스의 원소를 순서대로 변수에 담아 실행합니다.
    for i in range(n): 0부터 n - 1까지 순회합니다.
    for i in range(start, end): start부터 end - 1까지 순회합니다. 
    1
2

4
5
    for i in range(5):
    print(i)

for ch in "abc":
    print(ch)

    용어 설명
    순회 시퀀스의 원소를 처음부터 끝까지 차례로 꺼내는 것
    range() 연속된 정수를 만들어 주는 내장 함수
    • range(5)의 끝 값 5는 포함되지 않으므로 0~4까지만 만들어집니다.
    • 반복할 때마다 변수에는 원소가 새로 대입되며, 변수 이름은 자유롭게 정할 수 있습니다(관례적으로 i를 사용).
    • 리스트 등 자료구조 순회는 자료구조에서 자세히 다룹니다.

    range의 인수¶

    range()에 인수를 세 개까지 줄 수 있으며, 세 번째 값은 한 번에 증가하는 간격입니다.

    형태 만들어지는 값
    range(5) 0, 1, 2, 3, 4
    range(1, 6) 1, 2, 3, 4, 5
    range(0, 10, 3) 0, 3, 6, 9
    range(5, 0, -1) 5, 4, 3, 2, 1
    range(3, 3) 없음 
    1
2
    for i in range(5, 0, -1):
    print(i)

    • 간격이 음수이면 값이 줄어들며, 이때 시작 값이 끝 값보다 커야 합니다.
    • 끝 값은 항상 포함되지 않습니다. 1부터 5까지 반복하려면 range(1, 6)을 사용합니다.
    • 시작 값과 끝 값이 같거나 방향이 맞지 않으면 아무것도 만들어지지 않아 반복하지 않습니다.

    반복 변수¶

    반복이 끝난 뒤에도 반복 변수에는 마지막으로 꺼낸 원소가 남아 있습니다.

    1
2
3
4
    for i in range(3):
    pass

print(i)

    1
    2
    • pass는 아무 동작도 하지 않는 문장이며, 블록을 비워 둘 수 없을 때 자리를 채우는 용도로 사용합니다.
    • 블록 안에서 반복 변수를 직접 바꿔도 다음 반복에서는 시퀀스의 다음 원소가 새로 대입됩니다.

    값 누적¶

    반복하면서 변수에 값을 더해 나가는 방식으로 합계나 개수를 구할 수 있습니다.

    1

    • 초기화 없이 total += n을 사용하면 NameError가 발생하며, 변수에 대한 설명은 변수에서 자세히 다룹니다.
    • += 같은 대입 연산자는 연산자에서 자세히 다룹니다.

    조건과 함께 사용¶

    반복 안에 조건문을 넣으면 조건을 만족하는 원소만 처리할 수 있습니다.

    1
2
3

    count = 0

for ch in "hello":
    if ch == "l":
        count += 1

print(count)

    중첩 for¶

    반복문 안에 또 다른 반복문을 쓰면, 바깥 반복이 한 번 실행될 때마다 안쪽 반복이 처음부터 끝까지 실행됩니다.

    1
2
3
    for i in range(1, 4):
    for j in range(1, 4):
        print(i, "x", j, "=", i * j)

3 x 2 = 6
3 x 3 = 9

    • 안쪽 반복문은 한 단계 더 들여씁니다.

    3. while¶

    조건이 True인 동안 반복합니다. 반복 횟수를 사전에 알 수 없을 때 사용합니다.

    구성 요소 의미
    조건 매 반복 전에 확인하며, False가 되면 반복을 멈춥니다. (예: count < 3) 
    1
2
3
4
    count = 0
while count < 3:
    print(count)
    count += 1

    1
2
3
    0
1
2
    용어 설명
    무한 루프 조건이 계속 True여서 끝나지 않는 반복
    • 블록 안에서 조건에 쓰이는 변수를 바꾸지 않으면(count += 1 생략) 무한 루프가 되므로 주의해야 합니다.
    • 처음부터 조건이 False이면 블록은 한 번도 실행되지 않습니다.
    • 조건식에는 연산자의 비교 연산자와 논리 연산자를 사용합니다.

    반복 전 조건 확인¶

    while은 블록을 실행하기 전에 조건을 먼저 확인하므로, 처음부터 False이면 블록을 건너뜁니다.

    1
2
3
4
5
6
    x = 5

while x < 3:
    print("실행되지 않음")

print("건너뜀")

    건너뜀

    카운트다운¶

    조건에 쓰이는 변수를 줄여 가며 반복할 수도 있습니다.

    1

    n = 3

    print(n)
    n -= 1

    • 반복할 때마다 n이 줄어 0이 되면 조건이 False가 되어 반복이 끝납니다.

    무한 루프와 break¶

    while True:로 일부러 무한 루프를 만들고, 종료 조건을 만족하면 break로 빠져나오는 방식을 자주 사용합니다.

    1
2
3
4
5
6
7
8
    n = 0

while True:
    n += 1
    if n == 3:
        break

print(n)

    1
    3
    • 종료 조건이 블록 중간에 있거나 반복 횟수를 알 수 없을 때 유용합니다.
    • 빠져나오는 조건이 없으면 프로그램이 끝나지 않으며, 터미널에서는 Ctrl + C로 강제 종료할 수 있습니다.
    • 사용자에게 값을 입력받는 방법은 입력에서 자세히 다룹니다.

    for와 while의 선택¶

    상황 적합한 반복문
    정해진 횟수만큼 반복 for
    문자열·리스트의 원소를 차례로 처리 for
    조건이 바뀔 때까지 반복 while
    반복 횟수를 미리 알 수 없음 while
    • for는 원소가 떨어지면 자동으로 끝나므로 무한 루프에 빠질 위험이 적습니다.

    4. break와 continue¶

    반복문 실행 중 흐름을 제어합니다.

    키워드 동작
    break 반복문 전체를 즉시 종료합니다.
    continue 이번 반복의 남은 코드를 건너뛰고 다음 반복으로 이동합니다.

    용어 설명
    흐름 제어 반복문의 정상적인 진행을 중간에 바꾸는 것
    • 앞의 반복문은 i가 3이 되는 순간 break로 종료하고, 뒤의 반복문은 3일 때만 continue로 건너뜁니다.
    • break와 continue는 보통 조건문과 함께 사용합니다.
    • 중첩된 반복문에서는 break와 continue가 자신이 속한 가장 안쪽 반복문에만 적용됩니다.

    중첩 반복문의 break¶

    안쪽 반복문에서 break를 실행해도 바깥 반복문은 계속됩니다.

    1
2
3
4
5
    for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(i, j)

    1

2 0
    • j가 1이 되면 안쪽 반복만 끝나고, 바깥 반복은 다음 i로 넘어갑니다.

    while의 continue¶

    while에서는 continue로 건너뛰어도 조건에 쓰이는 변수의 변경이 빠지지 않도록 주의해야 합니다.

    1
2
3
4
5
6
7
    n = 0

while n < 5:
    n += 1
    if n == 2:
        continue
    print(n)

    1
2
3
4
    1
3
4
5
    • n += 1을 continue보다 뒤에 두면 n이 2에서 변하지 않아 무한 루프가 됩니다.
    • continue를 실행하면 곧바로 조건 확인으로 돌아가므로, 값을 바꾸는 코드는 continue보다 앞에 둡니다.

    반복이 끝까지 실행된 경우¶

    for와 while에는 else를 붙일 수 있으며, break 없이 반복이 정상적으로 끝났을 때만 실행됩니다.

    for i in range(5):
    if i == 9:
        break
else:
    print("break 없이 종료")

for i in range(5):
    if i == 2:
        break
else:
    print("실행되지 않음")

print("완료")

완료
    • 첫 번째 반복문은 break가 실행되지 않았으므로 else가 실행됩니다.
    • 두 번째 반복문은 break로 빠져나왔으므로 else가 실행되지 않습니다.
    • 찾는 값이 없는 경우를 처리할 때 사용하며, 자주 쓰이지 않으므로 이런 문법이 있다는 정도만 알아 둡니다.
