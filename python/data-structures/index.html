    자료구조¶

    ← Python으로 돌아가기

    초보자를 위한 안내

    처음에는 여러 값을 담는 list와 인덱스로 값을 꺼내는 방법, 키로 값을 찾는 dict의 기본 사용법만 익히면 충분합니다. tuple, set, 중첩 자료구조는 이런 것이 있다는 정도만 훑어보고, 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    자료구조는 여러 값을 하나로 묶어 저장하는 방식이며, 이 문서에서는 Python의 기본 자료구조인 list, tuple, dict, set과 이들을 겹쳐 쓰는 중첩 자료구조를 다룹니다.

    1. 자료구조란¶

    변수 하나에는 값 하나만 담을 수 있으므로, 값이 여러 개일 때는 자료구조로 묶어서 관리합니다. Python은 용도에 따라 네 가지 기본 자료구조를 제공하며, 각각 괄호 모양이 다릅니다.

    자료구조 표기 순서 변경 중복
    list [1, 2, 3] 있음 가능 허용
    tuple (1, 2, 3) 있음 불가 허용
    dict {"a": 1} 있음 가능 키는 불가
    set {1, 2, 3} 없음 가능 불가 
    1

    print(len([1, 2, 3]))
print(len((1, 2)))
print(len({"a": 1}))
print(len({1, 2, 2}))

    용어 설명
    자료구조 여러 값을 일정한 방식으로 묶어 저장하는 구조
    요소 자료구조 안에 들어 있는 각각의 값
    가변(mutable) 만든 뒤에 요소를 추가·수정·삭제할 수 있는 성질
    불변(immutable) 만든 뒤에 요소를 바꿀 수 없는 성질
    • len()은 자료구조에 들어 있는 요소의 개수를 반환합니다.
    • 모든 자료구조는 반복문의 for로 요소를 하나씩 순회할 수 있습니다.
    • 요소의 포함 여부는 연산자의 멤버십 연산자(in)로 확인합니다.

    어떤 자료구조를 쓸지¶

    저장하려는 값의 성격에 따라 알맞은 자료구조를 고릅니다.

    필요한 것 알맞은 자료구조 예시
    순서대로 모아 두고 추가·수정할 값 list 장바구니 상품 목록
    바뀌지 않는 값의 묶음 tuple 좌표 (3, 4)
    이름(키)으로 값을 찾을 때 dict 사용자 정보
    중복 없이 모으거나 포함 여부를 확인할 때 set 방문한 페이지 목록
    • 처음에는 대부분 list와 dict로 충분합니다.

    2. list¶

    요소를 순서대로 저장하는 가변 자료구조입니다. 대괄호([])로 만들며, 인덱스로 요소에 접근합니다.

    형태 의미
    list[i] i번째 요소를 반환합니다. 인덱스는 0부터 시작합니다.
    list[-1] 마지막 요소를 반환합니다.
    list.append(x) 맨 뒤에 요소를 추가합니다.
    list.remove(x) 값이 x인 첫 요소를 삭제합니다.

    인덱스 요소의 위치를 나타내는 번호 (0부터 시작)
    • 서로 다른 타입의 값도 한 리스트에 함께 담을 수 있습니다.
    • 범위를 벗어난 인덱스로 접근하면 IndexError가 발생합니다.
    • 문자열도 인덱스로 접근하는 방식이 같으며, 문자열에서 다룹니다.

    IndexError¶

    요소의 개수보다 큰 인덱스로 접근하면 IndexError가 발생합니다.

    • 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
    • 오류를 처리하는 방법은 예외 처리에서 자세히 다룹니다.

    remove(x) None 값이 x인 첫 요소를 삭제합니다.

    같은 리스트를 가리키는 경우¶

    리스트를 다른 변수에 대입하면 복사되는 것이 아니라 같은 리스트를 함께 가리킵니다. 한쪽을 바꾸면 다른 쪽에도 반영됩니다.

    • b = a는 같은 리스트에 이름을 하나 더 붙이는 것이므로 a도 함께 바뀝니다.
    • 별도의 복사본이 필요하면 copy()를 사용합니다.
    • 가변 값을 다룰 때의 이런 특성은 dict와 set에도 같습니다.

    3. tuple¶

    요소를 순서대로 저장하지만 만든 뒤에는 바꿀 수 없는 불변 자료구조입니다. 소괄호(())로 만들며, 인덱스로 접근하는 방식은 list와 같습니다.

    1
2
3
4
5
6
    point = (3, 4)

print(point[0])

x, y = point
print(x, y)

    1
2
    3
3 4
    용어 설명
    언패킹 자료구조의 요소를 여러 변수에 한 번에 나누어 대입하는 것 (x, y = point)
    • point[0] = 10처럼 요소를 바꾸려 하면 TypeError가 발생합니다.
    • 요소가 하나인 튜플은 (1,)처럼 쉼표를 붙여야 하며, 쉼표가 없으면 괄호로 묶은 값 (1)이 됩니다.
    • 함수가 여러 값을 반환하면(return a, b) 튜플로 묶여 반환됩니다.
    • 변수의 다중 할당(a, b = 1, 2)도 같은 원리입니다.

    바꿀 수 없는 성질¶

    튜플의 요소를 수정하려고 하면 TypeError가 발생합니다.

    1
2
3
    point = (3, 4)

point[0] = 10

    1
2
3
4
    Traceback (most recent call last):
  File "main.py", line 3, in <module>
    point[0] = 10
TypeError: 'tuple' object does not support item assignment
    • 값을 바꿔야 한다면 list를 사용하고, 바뀌면 안 되는 값은 tuple로 두면 실수로 수정하는 것을 막을 수 있습니다.
    • 튜플은 불변이므로 dict의 키로 사용할 수 있습니다.

    괄호 없이 만들기¶

    튜플은 괄호 없이 쉼표만으로도 만들 수 있으며, 요소가 하나일 때는 쉼표가 필수입니다.

    1
2
3
4
5
6

print(b, type(b))

2
3

1 <class 'int'>
    • 튜플을 만드는 것은 괄호가 아니라 쉼표입니다.
    • 실수로 값 뒤에 쉼표를 붙이면 의도하지 않게 튜플이 될 수 있습니다.

    4. dict¶

    키(key)와 값(value)을 짝지어 저장하는 가변 자료구조입니다. 중괄호({})에 키: 값 형태로 적으며, 인덱스 대신 키로 값에 접근합니다.

    형태 의미
    dict[key] 키에 해당하는 값을 반환합니다. 키가 없으면 KeyError가 발생합니다.
    dict[key] = value 키가 있으면 값을 수정하고, 없으면 새로 추가합니다.
    dict.get(key) 키에 해당하는 값을 반환하며, 키가 없으면 None을 반환합니다. 
    1
2
3
4
5
6
7
8
9
    user = {"name": "홍길동", "age": 25}

print(user["name"])

user["age"] = 26
user["city"] = "서울"
print(user)

print(user.get("phone"))

    1
2
3
    홍길동
{'name': '홍길동', 'age': 26, 'city': '서울'}
None
    용어 설명
    키(key) 값을 찾는 데 쓰는 이름표. 중복될 수 없고 불변 값이어야 함
    값(value) 키에 연결되어 저장된 데이터
    • 키는 문자열, 숫자, 튜플처럼 불변 값만 사용할 수 있습니다.
    • 같은 키로 값을 다시 대입하면 기존 값이 덮어써집니다.
    • for key, value in user.items():로 키와 값을 함께 순회할 수 있습니다.
    • 키워드 인수를 딕셔너리로 받는 방법은 함수의 가변 인수에서 다룹니다.

    KeyError¶

    없는 키로 dict[key]에 접근하면 KeyError가 발생합니다.

    1
2
3
    user = {"name": "홍길동", "age": 25}

print(user["phone"])

    1
2
3
4
    Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(user["phone"])
KeyError: 'phone'
    • 키가 있는지 확실하지 않으면 get()을 사용합니다.
    • get(key, 기본값)처럼 두 번째 인수를 주면 키가 없을 때 None 대신 그 값을 반환합니다.
    • "phone" in user처럼 in으로 키의 존재 여부를 확인할 수도 있으며, 이때 확인 대상은 값이 아니라 키입니다.
    • 오류를 처리하는 방법은 예외 처리에서 자세히 다룹니다.

    • dict는 값을 넣은 순서를 유지하므로 순회하면 추가한 순서대로 꺼내집니다.
    • for key, value in ...처럼 변수 둘로 받는 것은 튜플 언패킹과 같은 원리입니다.

    5. set¶

    중복 없이 값을 저장하는 가변 자료구조입니다. 순서가 없어 인덱스로 접근할 수 없으며, 포함 여부 확인과 집합 연산에 사용합니다.

    형태 의미
    set.add(x) 요소를 추가합니다. 이미 있으면 변화가 없습니다.
    a & b 두 집합에 모두 있는 요소(교집합)를 반환합니다.
    a \| b 두 집합의 모든 요소(합집합)를 반환합니다.
    a - b a에만 있는 요소(차집합)를 반환합니다.

    용어 설명
    집합 중복 없이 요소를 모아 놓은 것
    교집합 두 집합에 공통으로 들어 있는 요소
    합집합 두 집합의 요소를 모두 합친 것
    차집합 한 집합에서 다른 집합의 요소를 뺀 것
    • 중복된 값은 자동으로 하나만 남으므로, 리스트의 중복을 제거할 때 set()으로 변환해 활용합니다.
    • 빈 집합은 {}가 아니라 set()으로 만듭니다. {}는 빈 dict입니다.
    • 순서가 없으므로 출력되는 요소의 순서를 기대하면 안 됩니다.

    중복 제거¶

    set()에 리스트를 넘기면 중복이 사라진 집합이 만들어집니다.

    • set(names)는 원본 names를 바꾸지 않고 새 집합을 만듭니다.

    자료구조의 요소로 다른 자료구조를 넣을 수 있습니다. 가장 흔한 형태는 사용자 여러 명을 dict로 표현하고 이를 list로 묶는 것입니다.

    {"name": "홍길동", "age": 25},

print(users[0]["name"])
print(users[1]["age"])

users[0]["age"] = 26
users.append({"name": "이영희", "age": 22})

for user in users:

    • 바깥은 순서가 필요한 list, 안쪽은 이름으로 값을 찾는 dict로 구성하는 형태가 자주 쓰입니다.
    • 중첩이 깊어질수록 접근식이 길어지므로, 한 단계씩 변수에 꺼내 두면 읽기 쉽습니다.
