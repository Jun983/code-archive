    연산자¶

    ← Java로 돌아가기

    초보자를 위한 안내

    처음에는 산술(+ - * / %), 비교(== != < >), 논리(&& || !) 연산자와 대입 연산자(=)만 익히면 충분합니다. 증감, 삼항, 비트 연산자와 우선순위의 세부 동작은 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 조건문과 반복문을 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    연산자는 값을 계산하거나 비교·조합할 때 사용하는 기호이며, 이 문서에서는 산술, 대입, 비교, 논리, 증감, 비트, 삼항 연산자와 String 연산, 연산자 우선순위를 다룹니다.

    1. 연산자란¶

    연산자는 하나 이상의 값(피연산자)을 계산해 새로운 값을 만드는 기호입니다. 연산자와 피연산자를 합친 것을 식이라 하며, 식은 계산이 끝나면 하나의 값이 됩니다.

    1
2
    int sum = 10 + 3;
System.out.println(sum);

    연산자 값을 계산하거나 비교·조합하는 기호
    피연산자 연산자가 계산하는 대상 값 (10 + 3에서 10, 3)
    식 연산자와 피연산자로 이루어져 하나의 값이 되는 코드
    산술 연산자 두 수를 계산하는 연산자
    대입 연산자 변수에 값을 할당하는 연산자
    비교 연산자 두 값을 비교하는 연산자
    논리 연산자 두 boolean 값을 조합하는 연산자
    증감 연산자 값을 1씩 증가·감소시키는 연산자
    비트 연산자 정수를 비트(0과 1) 단위로 계산하는 연산자
    삼항 연산자 조건에 따라 값을 선택하는 연산자
    • 변수에 값을 넣는 방법은 변수와 상수에서 다룹니다.

    두 수를 계산해 결과값을 반환합니다.

    연산자 의미
    + 왼쪽 값과 오른쪽 값을 더한 값을 반환합니다.
    - 왼쪽 값에서 오른쪽 값을 뺀 값을 반환합니다.
    * 왼쪽 값과 오른쪽 값을 곱한 값을 반환합니다.
    / 왼쪽 값을 오른쪽 값으로 나눈 몫을 반환합니다. 정수끼리는 소수점을 버립니다.
    % 왼쪽 값을 오른쪽 값으로 나눈 나머지를 반환합니다.

    복합 대입과 묵시적 형변환¶

    복합 대입 연산자(+= 등)는 계산 결과를 왼쪽 변수의 타입으로 자동 변환해 저장합니다. 그래서 =와 +를 따로 쓰면 컴파일 오류가 나는 코드도 복합 대입으로는 오류 없이 실행됩니다.

    • byte 범위(-128~127)를 넘는 c += 1은 오류 없이 -128로 넘칩니다. 값이 조용히 바뀌므로 주의해야 합니다.

    복합 대입을 쓰지 않은 경우¶

    같은 계산이라도 b = b + 5로 쓰면 b + 5가 int가 되어 byte에 담을 수 없으므로 컴파일 오류가 발생합니다.

    4. 비교 연산자¶

    두 값을 비교해 boolean을 반환합니다.

    실수의 비교¶

    실수는 이진수로 저장되어 0.1처럼 정확히 표현되지 않는 값이 있습니다. 그래서 계산 결과를 ==로 비교하면 예상과 다를 수 있습니다.

    public class DoubleCompareExample {
    public static void main(String[] args) {
        System.out.println(0.1 + 0.2);
        System.out.println(0.1 + 0.2 == 0.3);

        double diff = Math.abs((0.1 + 0.2) - 0.3);
        System.out.println(diff < 1e-9);
    }
}

    5. 논리 연산자¶

    두 boolean 값을 조합해 하나의 boolean을 반환합니다.

    \|\| 두 값 중 하나라도 true이면 true를 반환합니다.
    ! true는 false로, false는 true로 반환합니다.

    진리표¶

    두 값의 모든 조합에 대한 결과입니다.

    a b a && b a \|\| b !a
    true true true true false
    true false false true false
    false true false true true
    false false false false true

    단락 평가¶

    &&는 왼쪽이 false이면 오른쪽을 계산하지 않고, ||는 왼쪽이 true이면 오른쪽을 계산하지 않습니다. 결과가 이미 정해졌기 때문이며, 이를 단락 평가라고 합니다.

    public class ShortCircuitExample {
    public static void main(String[] args) {
        int x = 0;
        boolean safe = (x != 0) && (10 / x > 1);
        System.out.println(safe);

        int a = 5;
        boolean r1 = (a < 3) && (++a > 0);
        System.out.println(r1 + " " + a);

        int b = 5;
        boolean r2 = (b < 3) & (++b > 0);
        System.out.println(r2 + " " + b);

        int c = 5;
        boolean r3 = (c > 3) || (++c > 0);
        System.out.println(r3 + " " + c);
    }

    용어 설명
    단락 평가 왼쪽 값만으로 결과가 정해지면 오른쪽 식을 계산하지 않는 동작
    &, \| (boolean) 단락 평가 없이 양쪽을 항상 계산하는 논리 연산자
    • 첫 번째 줄에서 x != 0이 false이므로 10 / x는 계산되지 않아 ArithmeticException이 발생하지 않습니다. 이 성질로 "값이 있는지 확인한 뒤 사용"하는 조건을 안전하게 쓸 수 있습니다.
    • &&는 ++a를 실행하지 않아 a가 5 그대로지만, &는 양쪽을 모두 계산해 b가 6이 됩니다. &&, ||의 오른쪽에 증감 연산 같은 부수 효과가 있는 식을 두면 실행되지 않을 수 있습니다.

    7. 비트 연산자¶

    정수를 비트(0과 1) 단위로 계산합니다. 일반적인 계산보다는 상태 값을 하나의 정수에 모아 저장하거나 저수준 데이터를 다룰 때 사용합니다. 처음에는 이런 것이 있다는 정도만 확인해도 충분합니다.

    연산자 의미
    & 두 비트가 모두 1이면 1을 반환합니다.
    \| 두 비트 중 하나라도 1이면 1을 반환합니다.
    ^ 두 비트가 서로 다르면 1을 반환합니다.
    ~ 모든 비트를 뒤집습니다.
    << 비트를 왼쪽으로 옮깁니다. 한 칸마다 2배가 됩니다.
    >> 비트를 오른쪽으로 옮기고 왼쪽을 부호 비트로 채웁니다.
    >>> 비트를 오른쪽으로 옮기고 왼쪽을 0으로 채웁니다.

    public class BitExample {
    public static void main(String[] args) {
        int a = 0b1100;   // 12
        int b = 0b1010;   // 10

        System.out.println(Integer.toBinaryString(a & b));
        System.out.println(Integer.toBinaryString(a | b));
        System.out.println(Integer.toBinaryString(a ^ b));
        System.out.println(~a);
        System.out.println(a << 2);
        System.out.println(a >> 1);
        System.out.println(-16 >> 2);
        System.out.println(-16 >>> 28);
    }

    10. 연산자 우선순위¶

    하나의 식에 연산자가 여러 개 있으면 우선순위가 높은 연산자부터 계산합니다. 위쪽일수록 우선순위가 높습니다.

    순위 연산자 계산 방향
    1 x++ x-- 왼쪽 → 오른쪽
    2 ++x --x +x -x ~ ! 오른쪽 → 왼쪽
    3 * / % 왼쪽 → 오른쪽
    4 + - 왼쪽 → 오른쪽
    5 << >> >>> 왼쪽 → 오른쪽
    6 < <= > >= 왼쪽 → 오른쪽
    7 == != 왼쪽 → 오른쪽
    8 & 왼쪽 → 오른쪽
    9 ^ 왼쪽 → 오른쪽
    10 \| 왼쪽 → 오른쪽
    11 && 왼쪽 → 오른쪽
    12 \|\| 왼쪽 → 오른쪽
    13 ? : 오른쪽 → 왼쪽
    14 = += -= 등 오른쪽 → 왼쪽 
    1

    public class PrecedenceExample {
    public static void main(String[] args) {
        System.out.println(2 + 3 * 4);
        System.out.println((2 + 3) * 4);
        System.out.println(3 + 4 > 6 ? "크다" : "작다");
        System.out.println(true || false && false);
        System.out.println((true || false) && false);
    }
}

    • &&가 ||보다 우선순위가 높아 true || false && false는 true || (false && false)로 계산되어 true가 됩니다.
    • 헷갈리는 식은 외우지 말고 괄호로 순서를 분명히 표시하는 것이 좋습니다.
