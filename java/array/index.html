    배열¶

    ← Java로 돌아가기

    초보자를 위한 안내

    처음에는 배열을 선언하고 초기화하는 방법, 인덱스로 원소를 읽고 수정하는 방법, for문으로 순회하는 방법만 익히면 충분합니다. 기본값, 참조 복사와 값 복사의 차이는 이런 것이 있다는 정도만 훑어보고, 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    배열은 같은 타입의 값을 순서대로 묶어 보관하는 자료구조이며, 이 문서에서는 배열의 선언과 초기화, 원소 접근과 수정, 순회, 배열 복사와 비교, Arrays 유틸리티, 배열 활용 패턴을 다룹니다.

    1. 배열이란¶

    변수 하나에는 값 하나만 담을 수 있어서, 비슷한 값이 여러 개일 때 score1, score2처럼 변수를 계속 만들어야 합니다. 배열을 사용하면 같은 타입의 값을 하나의 이름으로 묶어 관리할 수 있습니다.

    용어 설명
    배열 같은 타입의 값을 순서대로 묶어 보관하는 자료구조
    원소 배열에 담긴 각각의 값
    인덱스 원소의 위치를 나타내는 번호. 0부터 시작하며 마지막은 length - 1
    길이 배열에 담을 수 있는 원소의 개수. 배열명.length로 구함
    • 배열은 한 번 만들면 길이를 바꿀 수 없습니다.
    • 한 배열에는 같은 타입의 값만 담을 수 있습니다.
    • 변수에 대한 기본 내용은 변수, 타입의 종류는 타입에서 자세히 다룹니다.

    배열의 길이¶

    배열의 길이는 만들 때 정해지며 이후에 바꿀 수 없습니다. length는 읽기만 가능하므로 값을 대입하면 컴파일 오류가 발생합니다.

    1
2
    int[] x = new int[3];
x.length = 5;

    1
2

    Main.java:8: error: cannot assign a value to final variable length
        x.length = 5;
         ^
    • 더 많은 원소가 필요하면 새 배열을 만들어 값을 옮겨 담아야 합니다.
    • 길이가 자주 변하는 데이터는 컬렉션을 사용합니다.
    • 컴파일 오류 메시지의 세부 표시는 javac 버전에 따라 다를 수 있습니다.

    선언 오류¶

    크기와 초기값을 함께 지정하거나, 서로 다른 타입의 값을 섞으면 컴파일 오류가 발생합니다.

    int[] arr = new int[3]{1, 2, 3};

    1

    1
2
3

        int[] arr = {1, "2", 3};
                        ^
    • 크기를 쓰거나 값을 쓰거나 둘 중 하나만 지정합니다(new int[3] 또는 {1, 2, 3}).
    • 이미 선언한 변수에 arr = {4, 5, 6};처럼 중괄호만 쓰면 컴파일 오류가 발생합니다. 선언 이후에는 arr = new int[]{4, 5, 6};으로 씁니다.
    • 컴파일 오류 메시지의 세부 표시는 javac 버전에 따라 다를 수 있습니다.

    만들지 않은 배열을 사용한 경우¶

    배열 변수를 선언만 하고 new로 만들지 않으면 컴파일 오류가 발생하고, 변수에 null을 대입한 경우에는 런타임 예외가 발생합니다.

    • null은 배열이 없다는 뜻이므로 길이나 원소에 접근할 수 없습니다.
    • 오류 메시지의 세부 표시는 Java 버전과 컴파일 옵션에 따라 다를 수 있습니다.

    음수 크기로 만든 경우¶

    배열의 크기는 0 이상이어야 합니다. 음수이면 컴파일은 되지만 실행할 때 예외가 발생합니다.

    3. 원소 접근과 수정¶

    배열에 담긴 각 값을 원소라 하며, 인덱스로 접근합니다. 인덱스는 0부터 시작하고 마지막 원소의 인덱스는 length - 1입니다.

    인덱스 범위를 벗어난 경우¶

    존재하지 않는 인덱스를 사용하면 ArrayIndexOutOfBoundsException이 발생합니다. 길이가 3인 배열의 유효한 인덱스는 0~2이므로 3은 범위를 벗어납니다.

    1
2
    int[] scores = {90, 85, 70};
System.out.println(scores[3]);

    1
2
    Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3
    at Main.main(Main.java:4)
    • 읽을 때뿐 아니라 scores[3] = 100;처럼 쓸 때도 같은 오류가 발생합니다.
    • 오류 메시지의 Index 3은 사용한 인덱스, length 3은 배열의 길이입니다.
    • 마지막 원소는 scores[scores.length - 1]로 접근하며, 오류 처리 방법은 예외 처리에서 자세히 다룹니다.
    • 오류 메시지의 세부 표시는 Java 버전에 따라 다를 수 있습니다.

    4. 배열 순회¶

    인덱스 기반 for문 또는 for-each문으로 모든 원소를 순회합니다. for-each는 for (타입 변수 : 배열) 형태로, 인덱스 없이 값만 꺼낼 때 사용합니다.

    public class ArrayLoopExample {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};

        // 인덱스 기반 순회
        for (int i = 0; i < numbers.length; i++) {
            System.out.println(i + ": " + numbers[i]);

        for (int n : numbers) {
            System.out.println(n);
        }

    5. 배열 복사¶

    배열 변수는 배열 자체가 아니라 배열이 있는 위치(참조)를 담고 있습니다. 그래서 =로 대입하면 값이 복사되지 않고 같은 배열을 가리키게 됩니다.

    방식 예시 결과
    참조 복사 int[] b = a; a와 b가 같은 배열을 가리킴
    값 복사 int[] c = a.clone(); 내용이 같은 새 배열을 만듦

    public class ArrayCopyExample {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};

        int[] b = a;
        b[0] = 99;
        System.out.println(a[0]);
        System.out.println(a == b);

        int[] c = a.clone();
        c[0] = 1;
        System.out.println(a[0]);
        System.out.println(a == c);
    }
}

    • b를 바꿨는데 a[0]도 99가 된 것은 두 변수가 같은 배열을 가리키기 때문입니다.
    • clone()으로 만든 c는 별도의 배열이므로 c를 바꿔도 a는 바뀌지 않습니다.
    • a == c가 false인 것은 내용이 같아도 서로 다른 배열이기 때문입니다.
    • Arrays.copyOf(a, a.length)로도 값 복사를 할 수 있습니다.
    • 배열의 원소가 또 다른 배열이거나 객체이면 clone()은 원소의 참조만 복사하는 얕은 복사가 됩니다. 다차원 배열에서 자세히 다룹니다.

    6. Arrays 유틸리티¶

    java.util.Arrays 클래스는 배열을 다루는 메서드를 제공합니다. import java.util.Arrays;가 필요하며, Arrays.메서드명(배열) 형태로 호출합니다.

    메서드 설명
    Arrays.toString(arr) 배열의 내용을 [1, 2, 3] 형태의 문자열로 반환합니다.
    Arrays.sort(arr) 배열을 오름차순으로 정렬합니다. 원본 배열이 바뀝니다.
    Arrays.binarySearch(arr, key) 정렬된 배열에서 값의 인덱스를 찾습니다.
    Arrays.fill(arr, value) 모든 원소를 같은 값으로 채웁니다.
    Arrays.equals(a, b) 두 배열의 내용이 같은지 비교합니다.
    Arrays.copyOf(arr, length) 지정한 길이의 새 배열로 복사합니다.
    Arrays.copyOfRange(arr, from, to) from 이상 to 미만 범위를 새 배열로 복사합니다.

    public class ArrayPatternExample {
    public static void main(String[] args) {
        int[] scores = {72, 95, 60, 88};

        int sum = 0;
        int max = scores[0];
        int min = scores[0];
        for (int s : scores) {
            sum += s;
            if (s > max) max = s;
            if (s < min) min = s;
        }
        System.out.println(sum);
        System.out.println((double) sum / scores.length);
        System.out.println(max + " " + min);

        for (int i = 0, j = scores.length - 1; i < j; i++, j--) {
            int temp = scores[i];
            scores[i] = scores[j];
            scores[j] = temp;
        }
        System.out.println(java.util.Arrays.toString(scores));

        int target = 60;
        int index = -1;
        for (int i = 0; i < scores.length; i++) {
            if (scores[i] == target) {
                index = i;
                break;
            }
        }
        System.out.println(index);
    }
}

    순차 검색 배열을 처음부터 하나씩 비교해 값을 찾는 방법
    • 최댓값·최솟값은 첫 번째 원소로 시작해 더 큰(작은) 값을 만날 때마다 갱신합니다. 0으로 시작하면 음수만 있는 배열에서 틀립니다.
    • 평균은 sum / scores.length가 정수 나눗셈이 되므로 (double)로 형변환한 뒤 나눕니다. 연산자에서 자세히 다룹니다.
    • 뒤집기는 앞쪽(i)과 뒤쪽(j)의 값을 temp에 보관해 서로 바꾸고, 두 인덱스가 만날 때까지 반복합니다.
    • 찾는 값이 없으면 index가 -1로 남으므로, 찾았는지 여부를 확인할 수 있습니다.
