    타입¶

    ← Java로 돌아가기

    초보자를 위한 안내

    처음에는 int, double, boolean, char와 문자열(String)이 각각 어떤 값을 저장하는지만 익히면 충분합니다. byte, short, long, float의 범위와 참조 타입의 세부 동작은 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    타입은 저장할 수 있는 값의 종류와 크기를 정의하며, 이 문서에서는 Java의 타입을 구분하는 기본 타입과 참조 타입을 다룹니다.

    1. 타입이란¶

    Java는 정적 타입 언어이므로, 모든 값에는 컴파일 시점에 정해지는 타입이 있습니다. 타입에 따라 저장할 수 있는 값의 범위와 차지하는 메모리 크기가 달라집니다.

boolean isStudent = true;

System.out.println(age);
System.out.println(height);
System.out.println(isStudent);

    타입 저장할 수 있는 값의 종류와 크기를 정한 분류
    기본 타입 값 자체를 직접 저장하는 8가지 타입
    참조 타입 객체를 가리키는 타입
    • 변수를 선언하고 사용하는 방법은 변수와 상수에서 자세히 다룹니다.

    2. 기본 타입 (Primitive Type)¶

    값 자체를 직접 저장하는 8가지 타입입니다.

    타입 종류 크기 기본값 범위
    byte 정수 1 byte 0 -128 ~ 127
    short 정수 2 byte 0 -32,768 ~ 32,767
    int 정수 4 byte 0 약 -21억 ~ 21억
    long 정수 8 byte 0L 약 -922경 ~ 922경
    float 실수 4 byte 0.0f 소수점 약 7자리
    double 실수 8 byte 0.0 소수점 약 15자리
    char 문자 2 byte '\0' 0 ~ 65,535 (유니코드)
    boolean 논리 1 byte false true / false
    용어 설명
    유니코드 전 세계 문자를 하나의 숫자 번호로 표현하는 국제 표준 (예: 'A'=65, '가'=44032)
    • 접미사가 없으면 정수는 int, 실수는 double로 처리됩니다.
    • long은 L, float은 f를 붙여 구분합니다 (예: 100L, 3.14f).

    범위를 넘는 값¶

    타입의 범위를 벗어나는 리터럴을 쓰면 컴파일 오류가 발생합니다.

    1
    int big = 3000000000;

    1
2
3
    Main.java:3: error: integer number too large
        int big = 3000000000;
                  ^
    • 3000000000L처럼 L을 붙여 long으로 선언하면 해결됩니다.
    • 컴파일 오류 메시지의 세부 표시는 javac 버전에 따라 다를 수 있습니다.
    • double 값을 float에 넣을 때 f를 빼먹는 경우도 같은 방식으로 컴파일 오류가 발생하며, 타입 캐스팅에서 자세히 다룹니다.

    타입이 다른 값의 연산¶

    타입이 다른 기본 타입끼리 연산하면 더 큰 타입으로 맞춰져 계산됩니다. 정수끼리의 나눗셈은 정수 결과를, 문자열과의 +는 문자열 연결을 만듭니다.

    public static void main(String[] args) {
        System.out.println(1 + 2.0);
        System.out.println(10 / 4);
        System.out.println(10 / 4.0);
        System.out.println('A' + 1);
        System.out.println("A" + 1);
        System.out.println(1 + 2 + "3" + 4 + 5);
    }
}

    식 결과 타입 설명
    1 + 2.0 double int가 double로 맞춰짐
    10 / 4 int 소수점 이하가 버려짐
    'A' + 1 int char가 문자 코드(65)로 계산됨
    "A" + 1 String 숫자가 문자열로 바뀌어 연결됨
    • 1 + 2 + "3" + 4 + 5는 왼쪽부터 계산하므로 1 + 2 = 3까지는 숫자 덧셈이고, "3"을 만난 뒤부터 문자열 연결이 됩니다.
    • 자동 변환의 규칙은 타입 캐스팅에서 자세히 다룹니다.

    오버플로¶

    정수 타입은 표현 범위가 정해져 있어, 범위를 넘으면 예외 없이 반대쪽 끝값으로 되돌아갑니다.

    public static void main(String[] args) {

        System.out.println(Long.MAX_VALUE + 1);

        byte b = 127;
        b++;
        System.out.println(b);

        System.out.println(2147483647 * 2);
        System.out.println(2147483647 * 2L);

}

    용어 설명
    오버플로 (Overflow) 값이 타입의 범위를 넘어 반대쪽 끝으로 되돌아가는 현상
    Integer.MAX_VALUE int가 표현할 수 있는 최댓값 (2,147,483,647)
    • 2147483647 * 2는 int 연산이라 오버플로가 발생하고, 한쪽을 long(2L)으로 바꾸면 long으로 계산되어 정상 값이 나옵니다.
    • 범위를 넘으면 예외를 던지고 싶다면 Math.addExact처럼 Exact가 붙은 메서드를 사용합니다. 범위를 넘으면 ArithmeticException: integer overflow가 발생합니다.

    실수의 오차¶

    float와 double은 이진수로 값을 저장하므로 0.1 같은 값을 정확히 표현하지 못해 계산에 작은 오차가 생길 수 있습니다.

    1
    System.out.println(0.1 + 0.2);

    1
    0.30000000000000004
    • 실수는 ==로 같은지 비교하지 않고, 오차 범위 안인지 확인합니다.
    • 정확한 소수 계산이 필요하면 BigDecimal을 사용합니다.

    0으로 나누기¶

    정수를 0으로 나누면 예외가 발생하지만, 실수를 0으로 나누면 Infinity가 됩니다.

    1
2
    System.out.println(1.0 / 0);
System.out.println(10 / 0);

    3. 참조 타입 (Reference Type)¶

    객체를 가리키는 타입입니다. 기본 타입이 값 자체를 저장하는 것과 달리, 참조 타입은 객체가 있는 메모리 위치(주소)를 저장합니다. null을 가질 수 있습니다.

    1
2
3
4
5
    String name = "홍길동";
String empty = null;

System.out.println(name);
System.out.println(empty);

    1
2
    홍길동
null
    용어 설명
    객체 데이터와 기능을 하나로 묶은 단위
    null 아무것도 가리키지 않는 상태. 기본 타입은 null을 가질 수 없음
    • 객체를 직접 정의하고 생성하는 방법은 클래스와 객체에서 다룹니다.
    • 대표적인 참조 타입인 문자열은 String 클래스에서 자세히 다룹니다.

    null 참조 오류¶

    null인 참조 변수의 메서드를 호출하면 런타임 예외가 발생합니다.

    1
2
    String empty = null;
System.out.println(empty.length());

    1
2
    Exception in thread "main" java.lang.NullPointerException: Cannot invoke "String.length()" because "empty" is null
    at Main.main(Main.java:4)
    • 오류 메시지는 JDK 버전과 컴파일 옵션에 따라 다를 수 있습니다.
    • 예외의 처리 방법은 예외 처리에서 자세히 다룹니다.

    4. var¶

    var는 변수의 타입을 직접 쓰는 대신 초기값을 보고 컴파일러가 타입을 정하게 하는 키워드입니다(Java 10 이상). 타입이 사라지는 것이 아니라 컴파일 시점에 정해지므로 Java는 여전히 정적 타입 언어입니다.

    public class VarExample {
    public static void main(String[] args) {
        var n = 10;        // int
        var d = 3.5;       // double
        var s = "hi";      // String
        var l = 10L;       // long

        System.out.println(n + d);
        System.out.println(s.length());
    }
}

    var 초기값으로 타입을 추론해 지정하는 지역 변수용 키워드
    타입 추론 컴파일러가 값을 보고 타입을 자동으로 정하는 것
    • var는 메서드 안의 지역 변수에서만 쓸 수 있고, 필드나 메서드 매개변수에는 쓸 수 없습니다.
    • 변수가 한 번 정해진 타입은 바뀌지 않습니다.

    var 오류¶

    초기값이 없거나 null이면 타입을 추론할 수 없고, 추론된 타입과 다른 값을 대입할 수도 없습니다.

    5. 타입 확인¶

    instanceof¶

    instanceof는 참조 변수가 가리키는 객체가 특정 타입인지 boolean으로 확인합니다.

    public class InstanceofExample {
    public static void main(String[] args) {
        Object o = "text";

        System.out.println(o instanceof String);
        System.out.println(o instanceof Integer);

        if (o instanceof String str) {
            System.out.println(str.length());
        }
    }

    getClass¶

    getClass()는 객체의 실제 클래스 정보를 반환하며, getName()·getSimpleName()으로 이름을 얻습니다.

    기본 타입에 instanceof를 쓴 경우¶

    기본 타입 변수에는 instanceof를 사용할 수 없습니다.

    1
2
    int n = 5;
System.out.println(n instanceof Integer);

    1
2
3
4
5
    Main.java:4: error: unexpected type
        System.out.println(n instanceof Integer);
                           ^
  required: reference
  found:    int
    • 컴파일 오류 메시지의 세부 표시는 javac 버전에 따라 다를 수 있습니다.
    • 기본 타입의 타입은 변수를 선언한 타입으로 이미 정해져 있으므로, 실행 중에 타입을 확인하는 방법은 참조 타입에 주로 쓰입니다.
