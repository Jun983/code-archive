    조건문¶

    ← Java로 돌아가기

    초보자를 위한 안내

    처음에는 if/else if/else로 조건에 따라 코드를 나누는 방법과, 조건식을 소괄호(())로 감싸고 실행할 코드를 중괄호({})로 묶는 규칙만 익히면 충분합니다. switch의 fall-through, 화살표 문법, yield는 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    조건문은 조건식의 결과에 따라 실행할 코드 블록을 선택하는 문법이며, 이 문서에서는 if/else if/else, switch, switch 표현식, 삼항 연산자와의 선택 기준을 다룹니다.

    1. 조건문이란¶

    프로그램은 기본적으로 위에서 아래로 한 줄씩 실행되지만, 조건문을 사용하면 조건에 따라 일부 코드만 실행하거나 건너뛸 수 있습니다. 조건식은 true 또는 false로 평가되며, Java는 실행할 블록을 중괄호({})로 구분합니다.

    • if 블록은 조건이 true일 때만 실행되며, if 블록 밖의 System.out.println("종료")는 조건과 관계없이 항상 실행됩니다.

    조건식에는 boolean만 사용¶

    Java의 조건식은 boolean이어야 합니다. 0이나 1 같은 숫자를 조건으로 쓸 수 없습니다.

    2. if / else if / else¶

    조건이 true인 블록을 순서대로 찾아 실행하고, 나머지는 건너뜁니다.

    형태 의미
    if (조건) 조건이 true이면 블록을 실행합니다.
    else if (조건) 위 조건이 false이고 이 조건이 true이면 실행합니다.
    else 위의 모든 조건이 false이면 실행합니다.

    else if와 else는 필요할 때만 붙이며, 생략할 수 있습니다.

    용어 설명
    분기 조건에 따라 실행 흐름이 나뉘는 것
    else if "위 조건이 아니고 이 조건이면"을 뜻하는 추가 조건

    C2 -->|false| C3{score >= 70?}

    public class IfExample {
    public static void main(String[] args) {
        int score = 75;

        if (score >= 90) {
            System.out.println("A");
        } else if (score >= 80) {
            System.out.println("B");
        } else if (score >= 70) {
            System.out.println("C");
        } else {
            System.out.println("F");
        }
    }
}

    1
    C
    • else if는 여러 개 쓸 수 있고, 조건을 위에서부터 평가해 처음 true인 블록 하나만 실행합니다.
    • else는 항상 마지막에 한 번만 올 수 있습니다.

    점수 구간처럼 범위로 나눌 때는 조건의 순서가 결과를 바꿉니다. 처음 true인 블록만 실행되므로, 범위가 좁은 조건을 위에 둡니다.

    public class RangeConditionExample {
    public static void main(String[] args) {
        int score = 95;

        if (score >= 60) {
            System.out.println("D 이상");
        } else if (score >= 90) {
            System.out.println("A");

            System.out.println("유효한 점수");
        }
    }

    • 두 구간의 사이에 있는지는 0 <= score <= 100이 아니라 &&로 두 조건을 연결해 확인합니다.

    public class NestedIfExample {
    public static void main(String[] args) {
        int score = 85;
        boolean isAttended = true;

        if (score >= 80) {
            if (isAttended) {
                System.out.println("우수 출석");
            } else {
                System.out.println("우수 성적");
            }
        }
    }

    중괄호를 생략한 경우¶

    블록이 한 문장이면 중괄호를 생략할 수 있지만, 그러면 if에 속하는 문장은 바로 다음 한 줄뿐입니다. 들여쓰기를 맞춰도 실행 범위는 달라지지 않습니다.

    System.out.println("합격");

    1
    축하합니다

    3. switch¶

    하나의 값을 여러 case와 비교하여 일치하는 블록을 실행합니다.

    형태 의미
    case 값: 값이 일치하면 이 블록부터 실행합니다.
    break 현재 case 블록을 끝내고 switch를 빠져나옵니다.
    default: 일치하는 case가 없을 때 실행합니다. 
    flowchart TD
    Start([시작]) --> C1{day == 1?}
    C1 -->|true| M[월요일 출력]
    C1 -->|false| C2{day == 2?}
    C2 -->|true| T[화요일 출력]
    C2 -->|false| C3{day == 3?}
    C3 -->|true| W[수요일 출력]
    C3 -->|false| D[그 외 출력]
    M --> End([종료])
    T --> End
    W --> End
    D --> End

    public class SwitchExample {
    public static void main(String[] args) {
        int day = 3;

        switch (day) {
            case 1:
                System.out.println("월요일");
                break;
            case 2:
                System.out.println("화요일");
                break;
            case 3:
                System.out.println("수요일");
                break;
            default:
                System.out.println("그 외");
        }
    }
}

    1
    수요일
    • default는 생략할 수 있지만, 일치하는 case가 없을 때의 동작을 지정하려면 마지막에 둡니다.
    • switch에는 int, char, String, enum 등을 사용할 수 있으며 boolean, double, long은 사용할 수 없습니다.
    용어 설명
    fall-through break가 없어 일치한 case 이후의 case 블록까지 계속 실행되는 현상

    public class SwitchTypeExample {
    enum Level { LOW, MID, HIGH }

    public static void main(String[] args) {
        String command = "stop";
        switch (command) {
            case "go":
                System.out.println("출발");
                break;
            case "stop":
                System.out.println("정지");
                break;
            default:
                System.out.println("알 수 없음");
        }

        Level level = Level.MID;
        switch (level) {
            case LOW:
                System.out.println("낮음");
                break;
            case MID:
                System.out.println("중간");

    4. switch 표현식 (화살표 문법)¶

    Java 14부터는 case 값 -> 코드 형태의 화살표 문법으로 break 없이 fall-through 없는 switch를 작성할 수 있습니다. switch가 값을 반환하는 식으로도 쓰여서 이를 switch 표현식이라 합니다.

    형태 의미
    case 값 -> 코드 값이 일치하면 해당 코드만 실행하고 자동으로 종료됩니다(fall-through 없음).
    case 값1, 값2 -> 쉼표로 여러 값을 한 번에 처리합니다.
    yield 값 블록 형태에서 switch 표현식의 결과값을 반환합니다. 
     1

    public class SwitchArrowExample {
    public static void main(String[] args) {
        int day = 3;

        String result = switch (day) {
            case 1, 2, 3, 4, 5 -> "평일";
            case 6, 7 -> "주말";
            default -> "알 수 없음";
        };

        System.out.println(result);
    }
}

    평일
    • break나 fall-through를 신경 쓰지 않아도 되므로, Java 14 이상에서는 화살표 문법이 더 안전합니다.
    • 표현식으로 쓸 때는 끝에 세미콜론(;)을 붙입니다.

    public class YieldExample {
    public static void main(String[] args) {
        int score = 85;

        String msg = switch (score / 10) {
            case 10, 9 -> "최상";
            case 8 -> {
                String text = "상";

                yield "기타";
        };

    5. 삼항 연산자와 조건문¶

    값을 하나 고르는 단순한 분기는 삼항 연산자(조건 ? A : B)로 짧게 쓸 수 있습니다. 삼항 연산자의 기본 문법은 연산자에서 다룹니다.

    public class TernaryExample {
    public static void main(String[] args) {
        int max = 3 > 5 ? 3 : 5;
        System.out.println(max);

        int score = 75;
        String grade = score >= 90 ? "A" : score >= 80 ? "B" : score >= 70 ? "C" : "F";

    • 삼항 연산자는 else if처럼 위에서부터 평가해 처음 true인 값을 선택합니다.
    • 중첩이 두 단계를 넘으면 읽기 어려우므로 if/else if를 사용합니다.
    • 삼항 연산자는 값을 반환하는 식이므로 문장을 실행해야 하는 분기에는 쓸 수 없습니다.
