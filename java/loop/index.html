    반복문¶

    ← Java로 돌아가기

    초보자를 위한 안내

    처음에는 반복 횟수가 정해진 for와, 조건이 true인 동안 반복하는 while만 익히면 충분합니다. do-while, break/continue, 레이블, for-each는 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 배열을 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

    반복문은 조건이 만족되는 동안 코드 블록을 반복 실행하는 문법이며, 이 문서에서는 for, while, do-while, 향상된 for(for-each)와 반복 흐름을 제어하는 break, continue, 레이블을 다룹니다.

    1. 반복문이란¶

    같은 작업을 여러 번 해야 할 때 코드를 복사하는 대신 반복문을 사용하면, 조건이 만족되는 동안 블록을 되풀이해 실행할 수 있습니다.

    • 반복 조건에는 연산자의 비교 연산자를 사용하며, 흐름 분기는 조건문과 함께 자주 쓰입니다.

    반복문 오류¶

    조건이 영원히 false가 되지 않으면 무한 반복에 빠지고, for 헤더의 구분자를 빼먹으면 컴파일 오류가 발생합니다.

    • 무한 반복에 빠지면 터미널에서 Ctrl+C로 프로그램을 중단합니다.

    2. for¶

    반복 횟수가 정해진 경우에 사용합니다. for 뒤 괄호 안에 초기화·조건·증감식을 한 줄로 작성합니다.

    용어 의미
    초기화 반복 시작 전 한 번만 실행합니다. (예: int i = 0)
    조건 매 반복 전에 확인하며, false가 되면 반복을 멈춥니다. (예: i < 5)
    증감식 매 반복이 끝난 뒤 실행됩니다. (예: i++) 
    flowchart TD
    Start([시작]) --> Init[i = 0 초기화]
    Init --> C1{i < 5? 조건}
    C1 -->|true| Body[코드 실행]
    Body --> Inc[i++ 증감]
    Inc --> C1
    C1 -->|false| End([종료])

    반복 범위가 어긋난 경우¶

    조건을 <가 아니라 <=로 쓰면 배열의 길이를 넘어 접근해 런타임 예외가 발생합니다.

    int[] numbers = {10, 20, 30};
for (int i = 0; i <= numbers.length; i++) {
    System.out.println(numbers[i]);
}

    • 인덱스는 0~length - 1이므로 조건은 i < numbers.length로 씁니다.
    • 반복 횟수가 하나 많거나 적은 이런 실수를 off-by-one 오류라고 합니다.
    • 오류 메시지의 세부 표시는 Java 버전에 따라 다를 수 있습니다.

    3. while¶

    조건이 true인 동안 반복합니다. 반복 횟수를 사전에 알 수 없을 때 사용합니다.

    Inc --> C1
    C1 -->|false| End([종료])

    무한 루프와 break¶

    조건을 true로 두면 끝나지 않는 반복(무한 루프)이 됩니다. 반복 안에서 break로 빠져나오는 조건을 두면, 반복 횟수를 모르는 상황에서 유용합니다.

    public class InfiniteLoopExample {
    public static void main(String[] args) {
        int n = 1;
        while (true) {
            n *= 2;
            if (n > 50) {
                break;
            }
        }
        System.out.println(n);

        int count = 0;
        for (;;) {
            count++;
            if (count == 3) break;
        }
        System.out.println(count);
    }
}

    • 무한 루프 안에는 반드시 break나 return처럼 반복을 끝낼 수 있는 경로를 둡니다.

    • 입력을 받은 뒤 올바른 값인지 확인하며 다시 입력받는 것처럼, 일단 한 번은 실행해야 하는 경우에 사용합니다.
    • while (조건);처럼 do-while의 끝에는 세미콜론(;)이 필요합니다.

    public class LabelExample {
    public static void main(String[] args) {
        outer:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (i * j == 4) {
                    break outer;
                }
                System.out.println(i + "," + j);
            }
        }

        System.out.println("--");

        outer2:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == 2) continue outer2;
                System.out.println(i + "," + j);
            }
        }
    }

    break 레이블 레이블이 붙은 반복문 전체를 종료
    continue 레이블 레이블이 붙은 반복문의 다음 반복으로 이동
    • i * j == 4가 되는 i = 2, j = 2에서 break outer가 두 반복문을 모두 끝냅니다.
    • continue outer2는 안쪽 반복을 중단하고 바깥 반복의 다음 i로 넘어갑니다.
    • 레이블은 코드를 읽기 어렵게 만들 수 있으므로 꼭 필요할 때만 사용합니다.

    public class ForEachExample {
    public static void main(String[] args) {
        int[] scores = {90, 80, 70};
        int total = 0;
        for (int s : scores) {
            total += s;
        }
        System.out.println(total / scores.length);

        for (char c : "abc".toCharArray()) {
            System.out.print(c + "-");
        }
        System.out.println();
    }
}

    • s에는 매 반복마다 배열의 원소가 하나씩 복사되어 들어옵니다.
    • 인덱스가 필요하거나 원소를 수정해야 하면 일반 for를 사용합니다. 원소를 복사해 꺼내는 성질은 배열에서 자세히 다룹니다.
