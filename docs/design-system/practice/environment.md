# 환경 체크리스트

[← 실습편으로 돌아가기](index.md)

실습을 시작하기 전에 도구가 준비되었는지 확인합니다. 설치 방법과 도구별 설명은 [개발환경 준비](../setup.md)에서 다루므로 이 문서에서는 반복하지 않습니다.

---

## 도구 확인

| 도구 | 작업 | 기대 결과 | 확인 방법 |
|---|---|---|---|
| Figma | [샘플 Figma 파일](sample-file.md)을 직접 만듭니다. | 파일이 열리고 편집할 수 있습니다. | 마지막 단계의 확인 방법 |
| Node.js | 터미널에서 버전을 확인합니다. | 버전이 출력됩니다. | `node -v`, `npm -v` |
| 코드 에디터 | 작업 폴더를 엽니다. | 폴더의 파일 목록이 보입니다. | 에디터에서 폴더 열기 |

토큰 변환 도구와 AI 자동화 도구는 해당 실습(3번 이후)에서 필요할 때 준비합니다. 설치 확인 항목은 [개발환경 준비의 설치 확인](../setup.md#설치-확인)을 따릅니다.

!!! warning "확인 필요"
    수강생 PC의 OS와 Node.js 버전 편차는 아직 조사하지 않았습니다. 권장 버전과 OS별 차이는 확인한 뒤 이 문서에 추가합니다.

---

## 작업 폴더

실습 파일을 한곳에 모으기 위해 빈 작업 폴더를 하나 만듭니다.

1. **작업**: 원하는 위치에 `design-system-practice` 폴더를 만들고 코드 에디터로 엽니다.
2. **기대 결과**: 폴더가 비어 있는 상태로 열립니다.
3. **확인 방법**: 에디터의 파일 목록에 아무 파일도 없습니다.

이후 실습에서 만드는 토큰 파일과 컴포넌트 코드는 이 폴더 안에 둡니다.

---

## 시작 상태

아래 항목을 모두 확인하면 실습 2를 시작할 수 있습니다.

- [ ] 샘플 Figma 파일을 직접 만들었다.
- [ ] 만든 파일에서 레이어를 편집할 수 있다.
- [ ] 터미널에서 Node.js와 `npm`의 버전이 출력된다.
- [ ] 코드 에디터에서 빈 `design-system-practice` 폴더를 열 수 있다.
