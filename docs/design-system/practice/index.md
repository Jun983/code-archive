# 실습편

[← 디자인 시스템으로 돌아가기](../index.md)

개념 문서(#1~#5)를 직접 따라 해 보는 실습 자료입니다. 개념 설명은 개념 문서에 두고, 실습편에는 작업 순서와 확인 방법만 둡니다. 모든 실습은 같은 샘플 Figma 파일에서 시작하고, 마친 뒤 본인 파일에 같은 순서로 적용합니다.

---

## 실습 순서

| 순서 | 실습 | 입력 | 산출물 |
|---|---|---|---|
| 1 | [공통 준비](sample-file.md) | 이 문서의 제작 절차 | 직접 만든 샘플 파일, 준비된 작업 환경 |
| 2 | Figma 디자인 시스템 정리 | 직접 만든 샘플 파일 | 변수·스타일·네이밍이 정돈된 Figma 파일 |
| 3 | 디자인 토큰 추출·발행 | 정돈된 Figma 파일 | 코드용 디자인 토큰 파일 |
| 4 | React 컴포넌트 라이브러리 구축 | 토큰 파일 | 토큰을 사용하는 컴포넌트 |
| 5 | 개발 전달 산출물 정리 | 토큰 파일, 컴포넌트 | 문서와 사용 가이드 |

2~5번 실습은 이 문서에 아직 링크가 없으며, 작성되는 대로 추가합니다. 각 단계의 산출물이 다음 단계의 입력이므로 순서대로 진행합니다.

| 실습 | 참고하는 개념 문서 |
|---|---|
| 2 | [Figma 디자인 시스템 정리](../figma-organize.md) |
| 3 | [디자인 토큰 추출·발행](../design-tokens.md) |
| 4 | [React 컴포넌트 라이브러리 구축](../component-library.md) |
| 5 | [개발 전달 산출물 정리](../handoff.md) |

## 표기 규칙

각 단계는 아래 세 항목으로 작성합니다.

| 항목 | 설명 |
|---|---|
| 작업 | 직접 수행할 일 |
| 기대 결과 | 작업을 마친 뒤 화면이나 파일에서 보여야 하는 상태 |
| 확인 방법 | 기대 결과가 맞는지 확인하는 절차 |

기대 결과와 확인 방법이 맞지 않으면 다음 단계로 넘어가지 않고 작업을 다시 확인합니다.
