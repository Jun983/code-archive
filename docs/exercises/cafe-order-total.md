# 카페 주문 금액 합산기

[← 연습 문제로 돌아가기](index.md)

## 문제

카페에서 주문한 메뉴들의 가격을 입력받아 총 주문 금액을 계산하세요.

## 조건

- 주문할 메뉴의 개수를 먼저 입력받습니다.
- 입력받은 개수만큼 메뉴 가격을 순서대로 입력받습니다.
- 입력이 끝나면 총 주문 금액을 출력합니다.
- 입력한 개수가 1보다 작으면 "1 이상의 값만 입력 가능합니다."를 출력하고 다시 개수를 입력받습니다.

## 터미널 입출력 예시

예시1

```
주문할 메뉴의 개수를 입력하세요: 3

1번째 메뉴 가격을 입력하세요: 4500
2번째 메뉴 가격을 입력하세요: 3000
3번째 메뉴 가격을 입력하세요: 2500

총 주문 금액: 10000원
```

예시2

```
주문할 메뉴의 개수를 입력하세요: 2

1번째 메뉴 가격을 입력하세요: 4000
2번째 메뉴 가격을 입력하세요: 4000

총 주문 금액: 8000원
```

예시3

```
주문할 메뉴의 개수를 입력하세요: 4

1번째 메뉴 가격을 입력하세요: 5000
2번째 메뉴 가격을 입력하세요: 3500
3번째 메뉴 가격을 입력하세요: 2000
4번째 메뉴 가격을 입력하세요: 4500

총 주문 금액: 15000원
```

예시4

```
주문할 메뉴의 개수를 입력하세요: 0
1 이상의 값만 입력 가능합니다.
주문할 메뉴의 개수를 입력하세요: 2

1번째 메뉴 가격을 입력하세요: 4000
2번째 메뉴 가격을 입력하세요: 4000

총 주문 금액: 8000원
```
