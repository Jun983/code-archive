# 문자열 마스킹 처리

[← 연습 문제로 돌아가기](index.md)

## 문제

개인정보 보호를 위해 이름과 전화번호 일부를 `*`로 가리는 마스킹 처리를 해보세요.

## 조건

- 이름과 전화번호를 각각 입력받습니다.
- 이름은 첫 글자만 남기고 나머지는 `*`로 표시합니다.
- 전화번호는 마지막 4자리만 남기고 나머지는 `*`로 표시합니다.

## 터미널 입출력 예시

예시1

```
이름을 입력하세요: 홍길동
전화번호를 입력하세요: 01012345678

이름: 홍**
전화번호: *******5678
```

예시2

```
이름을 입력하세요: 김민수
전화번호를 입력하세요: 01098765432

이름: 김**
전화번호: *******5432
```

예시3

```
이름을 입력하세요: 이서연
전화번호를 입력하세요: 01055512345

이름: 이**
전화번호: *******2345
```
