# 로그인 시도 제한기

[← 연습 문제로 돌아가기](index.md)

## 문제

정해진 비밀번호와 입력값을 비교하여 로그인을 처리하고, 최대 시도 횟수를 넘으면 로그인을 차단하세요.

## 조건

- 정답 비밀번호는 프로그램 실행 시마다 무작위로 정해지는 4자리 숫자입니다.
- 비밀번호를 최대 3회까지 입력받을 수 있습니다.
- 입력한 비밀번호가 정답과 일치하면 "로그인에 성공했습니다."를 출력하고 프로그램을 종료합니다.
- 일치하지 않으면 "비밀번호가 일치하지 않습니다. 기회 N번 남았습니다."를 출력하고 다시 입력받습니다. (N은 남은 시도 횟수)
- 3회 모두 일치하지 않으면 "로그인이 차단되었습니다."를 출력하고 프로그램을 종료합니다.
- 입력한 비밀번호의 길이가 4자리가 아니면 "비밀번호는 4자리여야 합니다. 기회 N번 남았습니다."를 출력하고, 해당 입력도 시도 횟수에 포함합니다. (N은 남은 시도 횟수)
- 입력한 비밀번호에 숫자가 아닌 문자(특수 기호, 영문자 등)가 포함되어 있으면 "숫자만 입력 가능합니다. 기회 N번 남았습니다."를 출력하고, 해당 입력도 시도 횟수에 포함합니다. (N은 남은 시도 횟수)

## 터미널 입출력 예시

아래 예시는 정답 비밀번호가 `1234`로 정해진 경우를 가정합니다.

예시1

```
비밀번호를 입력하세요: 1234

로그인에 성공했습니다.
```

예시2

```
비밀번호를 입력하세요: 0000
비밀번호가 일치하지 않습니다. 기회 2번 남았습니다.
비밀번호를 입력하세요: 1234

로그인에 성공했습니다.
```

예시3

```
비밀번호를 입력하세요: 1111
비밀번호가 일치하지 않습니다. 기회 2번 남았습니다.
비밀번호를 입력하세요: 2222
비밀번호가 일치하지 않습니다. 기회 1번 남았습니다.
비밀번호를 입력하세요: 3333
비밀번호가 일치하지 않습니다. 기회 0번 남았습니다.

로그인이 차단되었습니다.
```

예시4

```
비밀번호를 입력하세요: 12
비밀번호는 4자리여야 합니다. 기회 2번 남았습니다.
비밀번호를 입력하세요: 1234

로그인에 성공했습니다.
```

예시5

```
비밀번호를 입력하세요: ab!@
숫자만 입력 가능합니다. 기회 2번 남았습니다.
비밀번호를 입력하세요: 1234

로그인에 성공했습니다.
```
