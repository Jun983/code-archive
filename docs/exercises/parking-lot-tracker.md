# 주차장 남은 자리 관리

[← 연습 문제로 돌아가기](index.md)

## 문제

주차장의 남은 자리 수를 입차와 출차에 따라 관리하는 프로그램을 구현하세요.

## 조건

- 주차장의 전체 자리 수를 입력받습니다.
- 이후 1(입차), 2(출차), 0(종료) 중 하나를 반복해서 입력받습니다.
- 입차 시 남은 자리가 없으면 "주차 공간이 없습니다."를 출력합니다.
- 출차 시 나갈 차량이 없다면 "나갈 차량이 없습니다."를 출력합니다.
- 입차 또는 출차 시 자리가 남았을 시 "N자리 남았습니다."를 출력합니다. (N은 남은 자리 수)
- 0을 입력하면 "프로그램을 종료합니다."를 출력하고 종료합니다.
- 1, 2, 0 이외의 값을 입력하면 "1, 2, 0 중 하나를 입력해주세요."를 출력합니다.

## 터미널 입출력 예시

예시1

```
주차장 전체 자리 수를 입력하세요: 3

1(입차), 2(출차), 0(종료) 중 하나를 입력하세요: 1
2자리 남았습니다.
1(입차), 2(출차), 0(종료) 중 하나를 입력하세요: 1
1자리 남았습니다.
1(입차), 2(출차), 0(종료) 중 하나를 입력하세요: 2
2자리 남았습니다.
1(입차), 2(출차), 0(종료) 중 하나를 입력하세요: 0
프로그램을 종료합니다.
```
