# 구구단 출력기

[← 연습 문제로 돌아가기](index.md)

## 문제

특정 단의 구구단을 1단부터 9단까지 출력하세요.

## 조건

- 출력할 단을 입력받습니다.
- 1부터 9까지 반복하며 `단 * i = 결과` 형태로 출력합니다.
- 입력한 단이 1~9 범위를 벗어나면 "1~9 사이의 값만 입력 가능합니다."를 출력하고 다시 단을 입력받습니다.

## 터미널 입출력 예시

예시1

```
출력할 단을 입력하세요: 3

3 * 1 = 3
3 * 2 = 6
3 * 3 = 9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27
```

예시2

```
출력할 단을 입력하세요: 5

5 * 1 = 5
5 * 2 = 10
5 * 3 = 15
5 * 4 = 20
5 * 5 = 25
5 * 6 = 30
5 * 7 = 35
5 * 8 = 40
5 * 9 = 45
```

예시3

```
출력할 단을 입력하세요: 7

7 * 1 = 7
7 * 2 = 14
7 * 3 = 21
7 * 4 = 28
7 * 5 = 35
7 * 6 = 42
7 * 7 = 49
7 * 8 = 56
7 * 9 = 63
```

예시4

```
출력할 단을 입력하세요: 15
1~9 사이의 값만 입력 가능합니다.
출력할 단을 입력하세요: 3

3 * 1 = 3
3 * 2 = 6
3 * 3 = 9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27
```
