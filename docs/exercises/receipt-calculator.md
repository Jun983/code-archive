# 영수증 계산기

[← 연습 문제로 돌아가기](index.md)

## 문제

편의점에서 여러 상품을 구매했습니다. 각 상품의 가격과 수량으로 전체 결제 금액을 계산하고, 영수증 형태로 결과를 출력하세요.

## 조건

- 상품 종류는 3개로 다뤄야 합니다.
- 각 상품마다 이름, 가격, 수량을 순서대로 입력받습니다.
- 각 상품마다 가격과 수량을 곱해 소계를 구합니다.
- 모든 소계를 더해 총 결제 금액을 구합니다.
- 상품별 소계와 총 결제 금액을 함께 출력합니다.

## 터미널 입출력 예시

예시1

```
1번째 상품명 입력: 상품A
1번째 가격 입력: 1500
1번째 수량 입력: 2
2번째 상품명 입력: 상품B
2번째 가격 입력: 2000
2번째 수량 입력: 1
3번째 상품명 입력: 상품C
3번째 가격 입력: 1200
3번째 수량 입력: 3

========================
상품A 1500원 x 2개 = 3000원
상품B 2000원 x 1개 = 2000원
상품C 1200원 x 3개 = 3600원
------------------------
총 결제 금액: 8600원
========================
```

예시2

```
1번째 상품명 입력: 우유
1번째 가격 입력: 2500
1번째 수량 입력: 2
2번째 상품명 입력: 식빵
2번째 가격 입력: 3200
2번째 수량 입력: 1
3번째 상품명 입력: 계란
3번째 가격 입력: 4900
3번째 수량 입력: 1

========================
우유 2500원 x 2개 = 5000원
식빵 3200원 x 1개 = 3200원
계란 4900원 x 1개 = 4900원
------------------------
총 결제 금액: 13100원
========================
```

예시3

```
1번째 상품명 입력: 콜라
1번째 가격 입력: 1800
1번째 수량 입력: 3
2번째 상품명 입력: 과자
2번째 가격 입력: 1500
2번째 수량 입력: 4
3번째 상품명 입력: 아이스 아메리카노
3번째 가격 입력: 1000
3번째 수량 입력: 2

========================
콜라 1800원 x 3개 = 5400원
과자 1500원 x 4개 = 6000원
아이스 아메리카노 1000원 x 2개 = 2000원
------------------------
총 결제 금액: 13400원
========================
```
