# 온도 변환기

[← 연습 문제로 돌아가기](index.md)

## 문제

섭씨 온도를 입력받아 화씨로 변환하고, "덥다/춥다" 메시지를 함께 출력하세요.

변환 공식: `화씨 = 섭씨 * 9 / 5 + 32`

## 조건

- 섭씨 온도를 입력받습니다.
- 변환 공식에 따라 화씨 온도를 계산합니다.
- 섭씨 28도 이상이면 "더운 날씨입니다.", 그렇지 않으면 "추운 날씨입니다."를 출력합니다.

## 터미널 입출력 예시

예시1

```
섭씨 온도를 입력하세요: 30
화씨 온도: 86.0

더운 날씨입니다.
```

예시2

```
섭씨 온도를 입력하세요: 15
화씨 온도: 59.0

추운 날씨입니다.
```

예시3

```
섭씨 온도를 입력하세요: 28
화씨 온도: 82.4

더운 날씨입니다.
```
