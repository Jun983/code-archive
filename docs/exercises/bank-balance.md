# 은행 잔액 관리

[← 연습 문제로 돌아가기](index.md)

## 문제

간단한 은행 계좌의 입출금을 처리하는 프로그램을 작성하세요.

## 조건

- 초기 잔액을 입력받습니다.
- 입금액과 출금액을 각각 입력받습니다.
- 입금과 출금을 처리하여 잔액을 갱신합니다.
- 각 거래 후 잔액을 출력합니다.

## 터미널 입출력 예시

예시1

```
초기 잔액을 입력하세요: 50000
입금액을 입력하세요: 30000
입금 후 잔액은 80000원입니다.
출금액을 입력하세요: 20000
출금 후 잔액은 60000원입니다.
```

예시2

```
초기 잔액을 입력하세요: 30000
입금액을 입력하세요: 15000
입금 후 잔액은 45000원입니다.
출금액을 입력하세요: 5000
출금 후 잔액은 40000원입니다.
```

예시3

```
초기 잔액을 입력하세요: 100000
입금액을 입력하세요: 50000
입금 후 잔액은 150000원입니다.
출금액을 입력하세요: 70000
출금 후 잔액은 80000원입니다.
```
