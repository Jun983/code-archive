# BMI 계산기

[← 연습 문제로 돌아가기](index.md)

## 문제

키(m)와 몸무게(kg)를 입력받아 BMI(체질량지수)를 계산하고 출력하세요.

BMI 공식: `몸무게 / (키 * 키)`

## 조건

- 키(m)와 몸무게(kg)를 순서대로 입력받습니다.
- BMI 공식에 따라 계산합니다.
- 계산 결과는 소수점 둘째 자리까지 출력합니다.

## 터미널 입출력 예시

예시1

```
키(m)를 입력하세요: 1.75
몸무게(kg)를 입력하세요: 68

당신의 BMI 수치는 22.2입니다.
```

예시2

```
키(m)를 입력하세요: 1.68
몸무게(kg)를 입력하세요: 55

당신의 BMI 수치는 19.49입니다.
```

예시3

```
키(m)를 입력하세요: 1.82
몸무게(kg)를 입력하세요: 90

당신의 BMI 수치는 27.17입니다.
```
