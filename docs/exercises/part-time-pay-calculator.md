# 아르바이트 급여 계산기

[← 연습 문제로 돌아가기](index.md)

## 문제

아르바이트생의 시급과 근무시간, 야간 근무 여부를 입력받아 급여를 계산하세요.

야간 근무이면 기본급의 20%를 야간수당으로 추가 지급합니다.

## 조건

- 시급, 근무시간, 야간 근무 여부("예"/"아니오")를 순서대로 입력받습니다.
- 기본급 = 시급 × 근무시간으로 계산합니다.
- 야간 근무 여부에 따라 삼항 연산자로 총 급여를 계산합니다.
- 기본급과 총 급여를 함께 출력합니다.

## 터미널 입출력 예시

예시1

```
시급을 입력하세요: 10000
근무시간을 입력하세요: 5
야간 근무 여부를 입력하세요(예/아니오): 아니오

기본급: 50000원
총 급여: 50000원
```

예시2

```
시급을 입력하세요: 12000
근무시간을 입력하세요: 6
야간 근무 여부를 입력하세요(예/아니오): 예

기본급: 72000원
총 급여: 86400원
```

예시3

```
시급을 입력하세요: 9500
근무시간을 입력하세요: 8
야간 근무 여부를 입력하세요(예/아니오): 예

기본급: 76000원
총 급여: 91200원
```
