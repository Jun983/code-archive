# 회문 판별기

[← 연습 문제로 돌아가기](index.md)

## 문제

입력받은 문자열이 앞에서 읽으나 뒤에서 읽으나 같은 회문인지 판별하세요.

## 조건

- 문자열을 입력받습니다.
- 첫 글자와 마지막 글자, 두 번째 글자와 뒤에서 두 번째 글자와 같은 방식으로 끝까지 비교합니다.
- 모두 일치하면 "회문입니다.", 하나라도 다르면 "회문이 아닙니다."를 출력합니다.
- 빈 문자열을 입력하면 "문자열을 입력해주세요."를 출력합니다.

## 터미널 입출력 예시

예시1

```
문자열을 입력하세요: 기러기

회문입니다.
```

예시2

```
문자열을 입력하세요: 스퀴즈

회문이 아닙니다.
```

예시3

```
문자열을 입력하세요: 토마토

회문입니다.
```

예시4

```
문자열을 입력하세요: 

문자열을 입력해주세요.
```
