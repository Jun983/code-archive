# 출력

[← Python으로 돌아가기](index.md)

Python의 기본적인 출력 수단은 `print()` 함수이며, 이 문서에서는 값을 출력하는 방법과 출력 형식을 조절하는 방법을 다룹니다.

---

## 1. print() 개요

`print()`는 괄호 안의 값을 화면에 출력하는 내장 함수이며, 프로그램의 실행 결과를 확인하는 가장 기본적인 수단입니다.

```python
print("Hello, World!")
print(42)
print(3.14)
print(True)
print(None)
```

```text
Hello, World!
42
3.14
True
None
```

| 용어 | 설명 |
|---|---|
| 내장 함수 | import 없이 어디서나 호출할 수 있도록 Python에 기본 포함된 함수 |

## 2. 출력 규칙

- 문자열은 큰따옴표(`"`)와 작은따옴표(`'`) 중 어느 것을 써도 동일하게 동작합니다.
- 숫자, `True`, `None`은 따옴표 없이 그대로 출력합니다.
- 출력이 끝나면 줄 바꿈이 자동으로 추가되므로, 여러 번 호출하면 결과가 줄마다 나뉘어 출력됩니다.
- 값을 넘기지 않고 `print()`만 호출하면 빈 줄이 출력됩니다.

## 3. print() 동작

`print()`는 받은 값을 그대로 출력하지 않고, 각 값을 `str()`로 문자열로 변환한 뒤 출력합니다.

예시: `print(42)`는 정수 `42`를 전달받지만, 내부에서 `str(42)`를 호출한 결과인 `"42"`를 출력합니다.

| 용어 | 설명 |
|---|---|
| `str()` | 값을 사람이 읽기 좋은 문자열로 바꾸는 내장 타입 `str`의 호출 |

## 4. 이스케이프 문자

문자열 안에서 역슬래시(`\`)로 시작하는 문자는 줄 바꿈이나 탭 같은 특수한 문자를 나타냅니다.

```python
print("Hello\nWorld")
print("Name\tAge")
print("He said \"Hi\"")
print("C:\\new\\folder")
```

```text
Hello
World
Name	Age
He said "Hi"
C:\new\folder
```

| 표기 | 의미 |
|---|---|
| `\n` | 줄 바꿈 |
| `\t` | 탭 |
| `\"`, `\'` | 따옴표 문자 그대로 |
| `\\` | 역슬래시 문자 그대로 |

## 5. 여러 값 출력

여러 값을 쉼표로 나열하면 공백으로 구분해 한 줄에 출력합니다. 값의 종류가 달라도 동일하게 동작합니다.

```python
print(1, 2, 3)
print("Age:", 20)
```

```text
1 2 3
Age: 20
```

## 6. 구분자 변경

`sep`에 문자열을 넘기면 값 사이에 들어가는 구분자를 바꿀 수 있습니다. 기본값은 공백 한 칸(`" "`)입니다.

```python
print(2025, 10, 24, sep="-")
print("a", "b", "c", sep="")
print("a", "b", "c", sep="\n")
```

```text
2025-10-24
abc
a
b
c
```

## 7. 줄 바꿈 제어

`print()`는 출력 끝에 줄 바꿈(`\n`)을 자동으로 붙입니다. `end`에 문자열을 넘기면 이 기본 동작을 바꿀 수 있으며, 빈 문자열(`""`)을 넘기면 다음 출력이 줄 바꿈 없이 이어집니다.

```python
print("Hello", end="")
print(", World!")
print("A", end=" ")
print("B", end=" ")
print("C")
```

```text
Hello, World!
A B C
```

문자열에 변수 값을 끼워 넣어 출력하는 방법은 [문자열](string.md)에서 다룹니다.
