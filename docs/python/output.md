# 출력

[← Python으로 돌아가기](index.md)

`print()`는 값을 화면에 출력합니다.

---

## 1. 기본 출력

`print()`는 기본적으로 출력 후 줄 바꿈을 추가하므로, 여러 번 호출하면 결과가 줄마다 나뉘어 출력됩니다.

```python
print("Hello, World!")
print(42)
print(3.14)
```

```
Hello, World!
42
3.14
```

큰따옴표(`"`) 대신 작은따옴표(`'`)를 사용해도 동일하게 동작합니다.

값을 넘기지 않고 `print()`만 호출하면 빈 줄이 출력됩니다.

## 2. 여러 값 출력

여러 값을 쉼표로 나열하면 공백으로 구분해 출력합니다. 값의 종류가 달라도 동일하게 동작합니다.

```python
print(1, 2, 3)
print("Age:", 20)
```

```
1 2 3
Age: 20
```

!!! info "참고"
    `print()`는 기본적으로 줄 바꿈을 자동으로 추가하는데, 다음 출력과 줄 바꿈 없이 이어붙이고 싶다면 `end=""`를 넘겨 이 기본 동작을 바꿀 수 있습니다.
    ```python
    print("Hello", end="")
    print(", World!")
    ```
    ```
    Hello, World!
    ```
