# Python

Python은 간결한 문법과 동적 타입 시스템을 갖춘 인터프리터 언어로, 빠른 개발 속도와 높은 가독성을 지향합니다.

이 문서에서는 기본 문법·자료구조·함수 등 핵심 개념부터 클래스와 객체지향, 예외 처리, 이터레이터·제너레이터, 데코레이터, 동시성 처리를 정리합니다.
