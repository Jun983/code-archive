# 연산자

[← Python으로 돌아가기](index.md)

연산자는 값을 계산하거나 비교·조합할 때 사용하는 기호이며, 이 문서에서는 산술·문자열·대입·비교·논리·멤버십 연산자와 연산자 우선순위를 다룹니다.

---

## 1. 연산자란

연산자는 하나 이상의 값을 받아 새로운 값을 만들어 내는 기호나 키워드입니다. 연산 대상이 되는 값은 피연산자라고 하며, `3 + 4`에서 `+`는 연산자, `3`과 `4`는 피연산자입니다.

```python
print(3 + 4)
print(3 < 4)
print("a" in "abc")
```

```text
7
True
True
```

| 용어 | 설명 |
|---|---|
| 연산자 | 피연산자를 계산하거나 비교해 새로운 값을 만드는 기호 또는 키워드 |
| 피연산자 | 연산자가 처리하는 대상 값 |
| 단항 연산자 | 피연산자가 하나인 연산자 (`not`, `-x`) |
| 이항 연산자 | 피연산자가 둘인 연산자 (`+`, `==`, `and`) |

- 연산 결과는 값이므로 변수에 저장하거나 `print()`로 바로 출력할 수 있습니다.
- `and`, `or`, `not`, `in`처럼 기호가 아닌 영단어로 된 연산자도 있습니다.

---

## 2. 산술 연산자

숫자를 계산해 새로운 숫자를 반환합니다.

| 연산자 | 의미 |
|---|---|
| `+` | 왼쪽 값과 오른쪽 값을 더한 값을 반환합니다. |
| `-` | 왼쪽 값에서 오른쪽 값을 뺀 값을 반환합니다. |
| `*` | 왼쪽 값과 오른쪽 값을 곱한 값을 반환합니다. |
| `/` | 왼쪽 값을 오른쪽 값으로 나눈 값을 `float`로 반환합니다. |
| `//` | 나눗셈의 몫을 정수로 반환합니다 (버림 나눗셈). |
| `%` | 나눗셈의 나머지를 반환합니다. |
| `**` | 거듭제곱 값을 반환합니다. |

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

```text
13
7
30
3.3333333333333335
3
1
1000
```

| 용어 | 설명 |
|---|---|
| 버림 나눗셈 | 나눗셈 결과를 소수점 이하를 버리고 정수로 만드는 연산 (`//`) |

- `/`는 정수끼리 나눠도 항상 `float`를 반환합니다. 정수 몫이 필요하면 `//`를 사용합니다.
- `//`는 0에 가까운 쪽이 아니라 음의 무한대 쪽으로 내림하므로 `-7 // 2`는 `-4`입니다.
- `%`는 홀수·짝수 판별(`n % 2`)처럼 나머지가 필요할 때 자주 사용합니다.
- 숫자 간 `+`는 덧셈이지만, 문자열에 사용하면 이어 붙이기가 됩니다. 문자열에서의 동작은 다음 절에서 다룹니다.

---

## 3. 문자열 연산자

`+`와 `*`는 문자열에도 사용할 수 있으며, 숫자가 아니라 새로운 문자열을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `+` | 두 문자열을 이어 붙인 새 문자열을 반환합니다. |
| `*` | 문자열을 정수 횟수만큼 반복한 새 문자열을 반환합니다. |

```python
first = "Hello"
second = "Python"

print(first + " " + second)
print(first * 3)
print("-" * 10)
```

```text
Hello Python
HelloHelloHello
----------
```

| 용어 | 설명 |
|---|---|
| 연결 | 문자열을 `+`로 이어 붙이는 것 |
| 반복 | 문자열을 `*`로 여러 번 이어 붙이는 것 |

- `+`는 양쪽이 모두 문자열이어야 하며, `"나이: " + 25`처럼 숫자와 섞으면 `TypeError`가 발생합니다. 숫자는 `str()`로 변환해야 하며, 이는 [형변환](casting.md)에서 다룹니다.
- `*`의 반대편 피연산자는 정수여야 합니다.
- 문자열은 변경할 수 없으므로 연산할 때마다 원본은 그대로 두고 새 문자열이 만들어집니다.
- 비교(`==`)와 멤버십(`in`)도 문자열에 사용할 수 있으며, 각각 이후 절에서 다룹니다.

---

## 4. 대입 연산자

변수에 값을 할당합니다. `=` 외의 연산자는 산술 연산과 대입을 한 번에 수행하는 복합 대입 연산자입니다.

| 연산자 | 의미 |
|---|---|
| `=` | 오른쪽 값을 왼쪽 변수에 할당합니다. |
| `+=` | 변수에 오른쪽 값을 더한 뒤 할당합니다. |
| `-=` | 변수에서 오른쪽 값을 뺀 뒤 할당합니다. |
| `*=` | 변수에 오른쪽 값을 곱한 뒤 할당합니다. |
| `/=` | 변수를 오른쪽 값으로 나눈 뒤 할당합니다. |
| `//=` | 변수를 오른쪽 값으로 나눈 몫을 할당합니다. |
| `%=` | 변수를 오른쪽 값으로 나눈 나머지를 할당합니다. |

```python
count = 10

count += 5
print(count)

count -= 3
print(count)

count *= 2
print(count)

count //= 5
print(count)
```

```text
15
12
24
4
```

| 용어 | 설명 |
|---|---|
| 복합 대입 연산자 | 산술 연산과 대입을 합친 연산자 (`+=`, `-=` 등) |

- `count += 5`는 `count = count + 5`와 같은 의미입니다.
- `/=`를 사용하면 결과가 `float`가 되므로 변수의 타입이 바뀝니다.

---

## 5. 비교 연산자

두 값을 비교해 `bool`을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `==` | 두 값이 같으면 `True`를 반환합니다. |
| `!=` | 두 값이 다르면 `True`를 반환합니다. |
| `<` | 왼쪽 값이 오른쪽 값보다 작으면 `True`를 반환합니다. |
| `>` | 왼쪽 값이 오른쪽 값보다 크면 `True`를 반환합니다. |
| `<=` | 왼쪽 값이 오른쪽 값보다 작거나 같으면 `True`를 반환합니다. |
| `>=` | 왼쪽 값이 오른쪽 값보다 크거나 같으면 `True`를 반환합니다. |

```python
a = 10
b = 3

print(a == b)
print(a != b)
print(a < b)
print(a > b)
print(1 < b < 5)
```

```text
False
True
False
True
True
```

| 용어 | 설명 |
|---|---|
| 연쇄 비교 | 비교 연산자를 이어 붙여 `1 < b < 5`처럼 범위를 한 번에 검사하는 문법 |

- `=`는 대입, `==`는 비교이므로 혼동하지 않아야 합니다.
- 문자열도 `==`로 값(내용) 비교가 바로 됩니다.
- `1 < b < 5`는 `1 < b and b < 5`와 같은 의미입니다.

---

## 6. 논리 연산자

`bool` 값을 조합해 하나의 `bool`을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `and` | 두 값이 모두 `True`이면 `True`를 반환합니다. |
| `or` | 두 값 중 하나라도 `True`이면 `True`를 반환합니다. |
| `not` | `True`는 `False`로, `False`는 `True`로 반환합니다. |

```python
a = True
b = False

print(a and b)
print(a or b)
print(not a)
print(3 > 1 and 2 > 5)
```

```text
False
True
False
False
```

| 용어 | 설명 |
|---|---|
| 단락 평가 | 왼쪽 값만으로 결과가 정해지면 오른쪽 값을 평가하지 않는 동작 |

- 논리 연산에는 기호 대신 `and`, `or`, `not` 키워드를 사용합니다.
- `and`는 왼쪽이 `False`이면, `or`는 왼쪽이 `True`이면 오른쪽을 평가하지 않습니다.
- 조건문에서 여러 조건을 조합하는 방법은 [조건문](conditional.md)에서 다룹니다.

## 7. 멤버십 연산자

값이 시퀀스(문자열, 리스트 등)에 포함되어 있는지 확인합니다.

| 연산자 | 의미 |
|---|---|
| `in` | 왼쪽 값이 오른쪽 대상에 포함되면 `True`를 반환합니다. |
| `not in` | 왼쪽 값이 오른쪽 대상에 포함되지 않으면 `True`를 반환합니다. |

```python
word = "Hello"
numbers = [1, 2, 3]

print("H" in word)
print("ell" in word)
print(5 in numbers)
print(5 not in numbers)
```

```text
True
True
False
True
```

- 문자열에서는 한 글자뿐 아니라 부분 문자열도 확인할 수 있습니다.
- 리스트를 비롯한 자료구조는 [자료구조](data-structures.md)에서 다룹니다.

## 8. 연산자 우선순위

한 식에 연산자가 여러 개 있으면 우선순위가 높은 연산자부터 계산합니다.

| 순위 | 연산자 |
|---|---|
| 1 (높음) | `**` |
| 2 | `*`, `/`, `//`, `%` |
| 3 | `+`, `-` |
| 4 | `==`, `!=`, `<`, `>`, `<=`, `>=`, `in`, `not in` |
| 5 | `not` |
| 6 | `and` |
| 7 (낮음) | `or` |

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(True or False and False)
```

```text
14
20
512
True
```

- 괄호 `()`로 묶은 부분이 가장 먼저 계산됩니다.
- `**`는 오른쪽부터 계산하므로 `2 ** 3 ** 2`는 `2 ** 9`입니다.
- 우선순위가 헷갈리는 식은 괄호로 의도를 명확히 드러내는 편이 좋습니다.
