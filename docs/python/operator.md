# 연산자

[← Python으로 돌아가기](index.md)

!!! tip "초보자를 위한 안내"
    처음에는 산술 연산자(`+`, `-`, `*`, `/`), 비교 연산자(`==`, `<`, `>`), 논리 연산자(`and`, `or`, `not`)와 `=`와 `==`의 차이만 익히면 충분합니다. 우선순위 표를 외울 필요는 없으며, 헷갈리는 식은 괄호로 묶으면 됩니다. 나머지는 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

연산자는 값을 계산하거나 비교·조합할 때 사용하는 기호이며, 이 문서에서는 산술·문자열·대입·비교·논리·멤버십 연산자와 연산자 우선순위를 다룹니다.

---

## 1. 연산자란

연산자는 하나 이상의 값을 받아 새로운 값을 만들어 내는 기호나 키워드입니다. 연산 대상이 되는 값은 피연산자라고 하며, `3 + 4`에서 `+`는 연산자, `3`과 `4`는 피연산자입니다.

```python
print(3 + 4)
print(3 < 4)
print("a" in "abc")
```

```text
7
True
True
```

| 용어 | 설명 |
|---|---|
| 연산자 | 피연산자를 계산하거나 비교해 새로운 값을 만드는 기호 또는 키워드 |
| 피연산자 | 연산자가 처리하는 대상 값 |
| 단항 연산자 | 피연산자가 하나인 연산자 (`not`, `-x`) |
| 이항 연산자 | 피연산자가 둘인 연산자 (`+`, `==`, `and`) |

- 연산 결과는 값이므로 변수에 저장하거나 `print()`로 바로 출력할 수 있습니다.
- `and`, `or`, `not`, `in`처럼 기호가 아닌 영단어로 된 연산자도 있습니다.

### 연산자의 종류

이 문서에서 다루는 연산자는 용도에 따라 다음과 같이 나뉩니다.

| 종류 | 연산자 | 결과 |
|---|---|---|
| 산술 | `+`, `-`, `*`, `/`, `//`, `%`, `**` | 숫자 |
| 문자열 | `+`, `*` | 문자열 |
| 대입 | `=`, `+=`, `-=` 등 | 변수에 값 저장 |
| 비교 | `==`, `!=`, `<`, `>`, `<=`, `>=` | `bool` |
| 논리 | `and`, `or`, `not` | `bool` |
| 멤버십 | `in`, `not in` | `bool` |

- 같은 기호라도 피연산자의 [타입](type.md)에 따라 동작이 달라집니다. 예를 들어 `+`는 숫자에서는 덧셈, 문자열에서는 이어 붙이기입니다.

## 2. 산술 연산자

숫자를 계산해 새로운 숫자를 반환합니다.

| 연산자 | 의미 |
|---|---|
| `+` | 왼쪽 값과 오른쪽 값을 더한 값을 반환합니다. |
| `-` | 왼쪽 값에서 오른쪽 값을 뺀 값을 반환합니다. |
| `*` | 왼쪽 값과 오른쪽 값을 곱한 값을 반환합니다. |
| `/` | 왼쪽 값을 오른쪽 값으로 나눈 값을 `float`로 반환합니다. |
| `//` | 나눗셈의 몫을 정수로 반환합니다 (버림 나눗셈). |
| `%` | 나눗셈의 나머지를 반환합니다. |
| `**` | 거듭제곱 값을 반환합니다. |

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
```

```text
13
7
30
3.3333333333333335
3
1
1000
```

| 용어 | 설명 |
|---|---|
| 버림 나눗셈 | 나눗셈 결과를 소수점 이하를 버리고 정수로 만드는 연산 (`//`) |

- `/`는 정수끼리 나눠도 항상 `float`를 반환합니다. 정수 몫이 필요하면 `//`를 사용합니다.
- `//`는 0에 가까운 쪽이 아니라 음의 무한대 쪽으로 내림하므로 `-7 // 2`는 `-4`입니다.
- `%`는 홀수·짝수 판별(`n % 2`)처럼 나머지가 필요할 때 자주 사용합니다.
- 숫자 간 `+`는 덧셈이지만, 문자열에 사용하면 이어 붙이기가 됩니다. 문자열에서의 동작은 다음 절에서 자세히 다룹니다.

### 실수가 섞인 계산

피연산자 중 하나라도 `float`이면 결과도 `float`입니다.

```python
print(10 / 4)
print(7 // 2.0)
print(7 % 2.5)
print(2 ** -1)
```

```text
2.5
3.0
2.0
0.5
```

- `//`와 `%`도 실수가 섞이면 결과가 `float`가 됩니다.
- `**`의 지수가 음수이면 결과는 `float`입니다.
- `float` 계산에서 생기는 오차는 [타입](type.md)에서 자세히 다룹니다.

### 음수의 나눗셈

`//`와 `%`는 음수에서 직관과 다르게 보일 수 있습니다.

```python
print(-7 // 2)
print(-7 % 2)
print(7 % -2)
```

```text
-4
1
-1
```

- `%`의 결과는 오른쪽 피연산자와 같은 부호가 됩니다.
- `a // b * b + a % b`는 항상 `a`와 같습니다.

### 0으로 나누기

0으로 나누면 실행 중 `ZeroDivisionError`가 발생합니다.

```python
print("시작")
print(10 / 0)
print("끝")
```

```text
시작
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(10 / 0)
ZeroDivisionError: division by zero
```

- `/`, `//`, `%` 모두 오른쪽 값이 0이면 같은 오류가 발생합니다.
- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
- 오류를 처리하는 방법은 [예외 처리](exception.md)에서 자세히 다룹니다.

### 단항 연산자

`-`를 값 앞에 붙이면 부호를 바꿉니다.

```python
x = 5

print(-x)
print(-(-x))
```

```text
-5
5
```

## 3. 문자열 연산자

`+`와 `*`는 문자열에도 사용할 수 있으며, 숫자가 아니라 새로운 문자열을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `+` | 두 문자열을 이어 붙인 새 문자열을 반환합니다. |
| `*` | 문자열을 정수 횟수만큼 반복한 새 문자열을 반환합니다. |

```python
first = "Hello"
second = "Python"

print(first + " " + second)
print(first * 3)
print("-" * 10)
```

```text
Hello Python
HelloHelloHello
----------
```

| 용어 | 설명 |
|---|---|
| 연결 | 문자열을 `+`로 이어 붙이는 것 |
| 반복 | 문자열을 `*`로 여러 번 이어 붙이는 것 |

- `+`는 양쪽이 모두 문자열이어야 하며, `"나이: " + 25`처럼 숫자와 섞으면 `TypeError`가 발생합니다. 숫자는 `str()`로 변환해야 하며, 이는 [형변환](casting.md)에서 자세히 다룹니다.
- `*`의 반대편 피연산자는 정수여야 합니다.
- 문자열은 변경할 수 없으므로 연산할 때마다 원본은 그대로 두고 새 문자열이 만들어집니다.
- 비교(`==`)와 멤버십(`in`)도 문자열에 사용할 수 있으며, 각각 이후 절에서 자세히 다룹니다.

### 숫자 문자열의 연산

숫자 모양의 문자열도 문자열이므로 `+`는 이어 붙이기, `*`는 반복이 됩니다.

```python
print("3" + "4")
print("3" * 3)
print(int("3") + int("4"))
```

```text
34
333
7
```

- 숫자로 계산하려면 먼저 `int()`나 `float()`로 변환해야 합니다.

### 반복 횟수의 제한

`*`의 횟수가 0이거나 음수이면 빈 문자열이 되고, 정수가 아니면 `TypeError`가 발생합니다.

```python
print("ab" * 0 == "")
print("ab" * -1 == "")
print("ab" * 2.0)
```

```text
True
True
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print("ab" * 2.0)
TypeError: can't multiply sequence by non-int of type 'float'
```

- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
- 문자열을 만들고 다루는 방법은 [문자열](string.md)에서 자세히 다룹니다.

## 4. 대입 연산자

변수에 값을 할당합니다. `=` 외의 연산자는 산술 연산과 대입을 한 번에 수행하는 복합 대입 연산자입니다.

| 연산자 | 의미 |
|---|---|
| `=` | 오른쪽 값을 왼쪽 변수에 할당합니다. |
| `+=` | 변수에 오른쪽 값을 더한 뒤 할당합니다. |
| `-=` | 변수에서 오른쪽 값을 뺀 뒤 할당합니다. |
| `*=` | 변수에 오른쪽 값을 곱한 뒤 할당합니다. |
| `/=` | 변수를 오른쪽 값으로 나눈 뒤 할당합니다. |
| `//=` | 변수를 오른쪽 값으로 나눈 몫을 할당합니다. |
| `%=` | 변수를 오른쪽 값으로 나눈 나머지를 할당합니다. |

```python
count = 10

count += 5
print(count)

count -= 3
print(count)

count *= 2
print(count)

count //= 5
print(count)
```

```text
15
12
24
4
```

| 용어 | 설명 |
|---|---|
| 복합 대입 연산자 | 산술 연산과 대입을 합친 연산자 (`+=`, `-=` 등) |

- `count += 5`는 `count = count + 5`와 같은 의미입니다.
- `/=`를 사용하면 결과가 `float`가 되므로 변수의 타입이 바뀝니다.
- 변수를 만들고 값을 대입하는 방법은 [변수](variable.md)에서 자세히 다룹니다.

### 거듭제곱과 문자열

`**=`도 사용할 수 있으며, 문자열 변수에는 `+=`와 `*=`가 이어 붙이기와 반복으로 동작합니다.

```python
number = 5
number **= 2
print(number)

text = "a"
text += "b"
text *= 2
print(text)
```

```text
25
abab
```

### 값이 없는 변수

복합 대입 연산자는 변수의 현재 값을 사용하므로, 값이 대입되기 전의 변수에 쓰면 `NameError`가 발생합니다.

```python
total += 1
```

```text
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    total += 1
NameError: name 'total' is not defined
```

- 누적하려는 변수는 `total = 0`처럼 먼저 초기값을 대입해야 합니다.
- 반복문에서 값을 누적하는 방법은 [반복문](loop.md)에서 자세히 다룹니다.

## 5. 비교 연산자

두 값을 비교해 `bool`을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `==` | 두 값이 같으면 `True`를 반환합니다. |
| `!=` | 두 값이 다르면 `True`를 반환합니다. |
| `<` | 왼쪽 값이 오른쪽 값보다 작으면 `True`를 반환합니다. |
| `>` | 왼쪽 값이 오른쪽 값보다 크면 `True`를 반환합니다. |
| `<=` | 왼쪽 값이 오른쪽 값보다 작거나 같으면 `True`를 반환합니다. |
| `>=` | 왼쪽 값이 오른쪽 값보다 크거나 같으면 `True`를 반환합니다. |

```python
a = 10
b = 3

print(a == b)
print(a != b)
print(a < b)
print(a > b)
print(1 < b < 5)
```

```text
False
True
False
True
True
```

| 용어 | 설명 |
|---|---|
| 연쇄 비교 | 비교 연산자를 이어 붙여 `1 < b < 5`처럼 범위를 한 번에 검사하는 문법 |

- `=`는 대입, `==`는 비교이므로 혼동하지 않아야 합니다.
- 문자열도 `==`로 값(내용) 비교가 바로 됩니다.
- `1 < b < 5`는 `1 < b and b < 5`와 같은 의미입니다.

### 타입이 다른 값의 비교

`==`는 타입이 달라도 오류 없이 `False`를 반환하지만, 대소 비교는 `TypeError`가 발생합니다.

```python
print(1 == 1.0)
print(1 == "1")
print(1 < "2")
```

```text
True
False
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(1 < "2")
TypeError: '<' not supported between instances of 'int' and 'str'
```

- `int`와 `float`는 값이 같으면 `==`가 `True`입니다.
- 모양이 같아도 `1`과 `"1"`은 서로 다른 값입니다.
- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
- 문자열을 숫자로 바꿔 비교하는 방법은 [형변환](casting.md)에서 자세히 다룹니다.

### 문자열 비교

문자열은 `==`로 내용을 비교하고, `<`, `>`는 사전 순서로 비교합니다.

```python
print("abc" == "ABC")
print("apple" < "banana")
print("Z" < "a")
```

```text
False
True
True
```

- 대문자와 소문자는 서로 다른 문자이므로 `"abc" == "ABC"`는 `False`입니다.
- 대문자가 소문자보다 앞서므로 `"Z" < "a"`는 `True`입니다.
- 대소문자를 구분하지 않고 비교하려면 `lower()`로 통일한 뒤 비교하며, [문자열](string.md)에서 자세히 다룹니다.

### 실수의 비교

`float`는 근사값으로 저장되므로 계산 결과를 `==`로 비교하면 예상과 다를 수 있습니다.

```python
print(0.1 + 0.2 == 0.3)
print(abs(0.1 + 0.2 - 0.3) < 1e-9)
```

```text
False
True
```

- 계산한 실수는 `==` 대신 차이가 아주 작은지로 비교합니다.

## 6. 논리 연산자

`bool` 값을 조합해 하나의 `bool`을 반환합니다.

| 연산자 | 의미 |
|---|---|
| `and` | 두 값이 모두 `True`이면 `True`를 반환합니다. |
| `or` | 두 값 중 하나라도 `True`이면 `True`를 반환합니다. |
| `not` | `True`는 `False`로, `False`는 `True`로 반환합니다. |

```python
a = True
b = False

print(a and b)
print(a or b)
print(not a)
print(3 > 1 and 2 > 5)
```

```text
False
True
False
False
```

| 용어 | 설명 |
|---|---|
| 단락 평가 | 왼쪽 값만으로 결과가 정해지면 오른쪽 값을 평가하지 않는 동작 |

- 논리 연산에는 기호 대신 `and`, `or`, `not` 키워드를 사용합니다.
- `and`는 왼쪽이 `False`이면, `or`는 왼쪽이 `True`이면 오른쪽을 평가하지 않습니다.
- 조건문에서 여러 조건을 조합하는 방법은 [조건문](conditional.md)에서 자세히 다룹니다.

### 진리표

`and`와 `or`는 두 값의 조합에 따라 결과가 정해집니다.

| `a` | `b` | `a and b` | `a or b` |
|---|---|---|---|
| `True` | `True` | `True` | `True` |
| `True` | `False` | `False` | `True` |
| `False` | `True` | `False` | `True` |
| `False` | `False` | `False` | `False` |

### 단락 평가

왼쪽 값만으로 결과가 정해지면 오른쪽은 실행되지 않으므로, 오른쪽에서 오류가 날 식도 건너뜁니다.

```python
print(False and 1 / 0)
print(True or 1 / 0)
```

```text
False
True
```

- `1 / 0`은 `ZeroDivisionError`가 발생하는 식이지만, 평가되지 않으므로 오류 없이 결과가 출력됩니다.

### 피연산자를 반환하는 경우

`and`와 `or`는 피연산자가 `bool`이 아니면 `True`/`False`가 아니라 피연산자 중 하나를 그대로 반환합니다.

```python
print(0 or "기본값")
print("" or "기본값")
print("a" and "b")
print(0 and "b")
print(not 0)
```

```text
기본값
기본값
b
0
True
```

- `or`는 왼쪽이 참으로 취급되면 왼쪽을, 아니면 오른쪽을 반환합니다.
- `and`는 왼쪽이 거짓으로 취급되면 왼쪽을, 아니면 오른쪽을 반환합니다.
- `not`은 항상 `bool`을 반환합니다.
- `0`, `""` 같은 값이 거짓으로 취급되는 기준은 [조건문](conditional.md)에서 자세히 다룹니다.

## 7. 멤버십 연산자

값이 시퀀스(문자열, 리스트 등)에 포함되어 있는지 확인합니다.

| 연산자 | 의미 |
|---|---|
| `in` | 왼쪽 값이 오른쪽 대상에 포함되면 `True`를 반환합니다. |
| `not in` | 왼쪽 값이 오른쪽 대상에 포함되지 않으면 `True`를 반환합니다. |

```python
word = "Hello"
numbers = [1, 2, 3]

print("H" in word)
print("ell" in word)
print(5 in numbers)
print(5 not in numbers)
```

```text
True
True
False
True
```

- 문자열에서는 한 글자뿐 아니라 부분 문자열도 확인할 수 있습니다.
- 리스트를 비롯한 자료구조는 [자료구조](data-structures.md)에서 자세히 다룹니다.

### 문자열의 멤버십

문자열에서는 대소문자를 구분하며, 문자열이 아닌 값은 확인할 수 없습니다.

```python
print("A" in "abc")
print("" in "abc")
print(1 in "abc")
```

```text
False
True
Traceback (most recent call last):
  File "main.py", line 3, in <module>
    print(1 in "abc")
TypeError: 'in <string>' requires string as left operand, not int
```

- 빈 문자열은 모든 문자열에 포함된 것으로 취급됩니다.
- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.

### 딕셔너리와 집합의 멤버십

`dict`에서 `in`은 값이 아니라 키를 확인합니다.

```python
user = {"name": "지수"}
ids = {1, 2}

print("name" in user)
print("지수" in user)
print(3 in ids)
```

```text
True
False
False
```

- `dict`와 `set`은 [자료구조](data-structures.md)에서 자세히 다룹니다.

## 8. 연산자 우선순위

한 식에 연산자가 여러 개 있으면 우선순위가 높은 연산자부터 계산합니다.

| 순위 | 연산자 |
|---|---|
| 1 (높음) | `**` |
| 2 | `*`, `/`, `//`, `%` |
| 3 | `+`, `-` |
| 4 | `==`, `!=`, `<`, `>`, `<=`, `>=`, `in`, `not in` |
| 5 | `not` |
| 6 | `and` |
| 7 (낮음) | `or` |

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 ** 2)
print(True or False and False)
```

```text
14
20
512
True
```

- 괄호 `()`로 묶은 부분이 가장 먼저 계산됩니다.
- `**`는 오른쪽부터 계산하므로 `2 ** 3 ** 2`는 `2 ** 9`입니다.
- 우선순위가 헷갈리는 식은 괄호로 의도를 명확히 드러내는 편이 좋습니다.

### 같은 순위의 계산 순서

우선순위가 같은 연산자는 왼쪽에서 오른쪽으로 계산합니다. `**`만 예외로 오른쪽부터 계산합니다.

```python
print(10 - 3 - 2)
print(100 / 10 * 2)
```

```text
5
20.0
```

- `10 - 3 - 2`는 `(10 - 3) - 2`로 계산되어 `5`입니다.
- `100 / 10 * 2`는 `(100 / 10) * 2`이므로 `/`의 결과인 `float`가 이어져 `20.0`입니다.

### 부호와 비교, 논리의 우선순위

단항 `-`는 `**`보다 낮고 `*`보다 높으며, `not`은 비교보다 낮습니다.

```python
print(-2 ** 2)
print((-2) ** 2)
print(not 1 == 2)
```

```text
-4
4
True
```

- `-2 ** 2`는 `-(2 ** 2)`로 계산되므로 `-4`입니다. 음수를 제곱하려면 괄호로 묶습니다.
- `not 1 == 2`는 `1 == 2`를 먼저 계산한 뒤 `not`을 적용하므로 `not (1 == 2)`와 같습니다.
