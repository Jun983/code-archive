# 반복문

[← Python으로 돌아가기](index.md)

반복문은 같은 코드를 여러 번 실행하는 문법이며, 이 문서에서는 `for`, `while`, 반복 흐름을 제어하는 `break`와 `continue`를 다룹니다.

---

## 1. 반복문이란

같은 작업을 여러 번 해야 할 때 코드를 그대로 복사하는 대신 반복문을 사용하면 한 번만 작성해도 원하는 횟수만큼 실행할 수 있습니다. 반복문도 [조건문](conditional.md)처럼 들여쓰기로 반복할 블록을 구분합니다.

```python
for i in range(3):
    print("안녕")

print("종료")
```

```text
안녕
안녕
안녕
종료
```

| 용어 | 설명 |
|---|---|
| 반복문 | 블록을 여러 번 반복 실행하는 문장 |
| 반복(iteration) | 블록이 한 번 실행되는 것 |
| 루프 | 반복문이 반복되는 흐름 (반복문과 같은 의미로 쓰임) |

- 반복 횟수가 정해져 있거나 원소를 차례로 꺼낼 때는 `for`, 조건이 만족되는 동안 반복할 때는 `while`을 사용합니다.
- 들여쓰지 않은 `print("종료")`는 반복이 모두 끝난 뒤 한 번만 실행됩니다.

---

## 2. for

시퀀스(문자열, 리스트, `range()` 등)의 원소를 순서대로 하나씩 꺼내며 블록을 실행합니다. 초기화·조건·증감식을 직접 쓰지 않고, 꺼낼 원소가 없으면 자동으로 끝납니다.

| 형태 | 의미 |
|---|---|
| `for 변수 in 시퀀스:` | 시퀀스의 원소를 순서대로 변수에 담아 실행합니다. |
| `for i in range(n):` | `0`부터 `n - 1`까지 순회합니다. |
| `for i in range(start, end):` | `start`부터 `end - 1`까지 순회합니다. |

```python
for i in range(5):
    print(i)

for ch in "abc":
    print(ch)
```

```text
0
1
2
3
4
a
b
c
```

| 용어 | 설명 |
|---|---|
| 순회 | 시퀀스의 원소를 처음부터 끝까지 차례로 꺼내는 것 |
| `range()` | 연속된 정수를 만들어 주는 내장 함수 |

- `range(5)`의 끝 값 `5`는 포함되지 않으므로 `0`~`4`까지만 만들어집니다.
- 반복할 때마다 변수에는 원소가 새로 대입되며, 변수 이름은 자유롭게 정할 수 있습니다(관례적으로 `i`를 사용).
- 리스트 등 자료구조 순회는 [자료구조](data-structures.md)에서 다룹니다.

---

## 3. while

조건이 `True`인 동안 반복합니다. 반복 횟수를 사전에 알 수 없을 때 사용합니다.

| 구성 요소 | 의미 |
|---|---|
| 조건 | 매 반복 전에 확인하며, `False`가 되면 반복을 멈춥니다. (예: `count < 3`) |

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

```text
0
1
2
```

| 용어 | 설명 |
|---|---|
| 무한 루프 | 조건이 계속 `True`여서 끝나지 않는 반복 |

- 블록 안에서 조건에 쓰이는 변수를 바꾸지 않으면(`count += 1` 생략) 무한 루프가 되므로 주의해야 합니다.
- 처음부터 조건이 `False`이면 블록은 한 번도 실행되지 않습니다.
- 조건식에는 [연산자](operator.md)의 비교 연산자와 논리 연산자를 사용합니다.

---

## 4. break와 continue

반복문 실행 중 흐름을 제어합니다.

| 키워드 | 동작 |
|---|---|
| `break` | 반복문 전체를 즉시 종료합니다. |
| `continue` | 이번 반복의 남은 코드를 건너뛰고 다음 반복으로 이동합니다. |

```python
for i in range(5):
    if i == 3:
        break
    print(i)

for i in range(5):
    if i == 3:
        continue
    print(i)
```

```text
0
1
2
0
1
2
4
```

| 용어 | 설명 |
|---|---|
| 흐름 제어 | 반복문의 정상적인 진행을 중간에 바꾸는 것 |

- 앞의 반복문은 `i`가 `3`이 되는 순간 `break`로 종료하고, 뒤의 반복문은 `3`일 때만 `continue`로 건너뜁니다.
- `break`와 `continue`는 보통 [조건문](conditional.md)과 함께 사용합니다.
- 중첩된 반복문에서는 `break`와 `continue`가 자신이 속한 가장 안쪽 반복문에만 적용됩니다.
