# Python 개요

이 문서에서는 Python 소스 코드가 바이트코드로 변환되고 PVM에서 실행되기까지의 과정을 다룹니다.

## 1. 소스 코드

Python 소스 코드는 사람이 읽고 쓰는 텍스트 형태의 `.py` 파일입니다. 메모장이나 VSCode 같은 어떤 편집기로도 작성할 수 있으며, 기본 문자 인코딩은 UTF-8이므로 한글도 별도 설정 없이 사용할 수 있습니다. 이 파일은 실행 전까지 사람만 이해할 수 있는 글일 뿐, 컴퓨터가 직접 실행할 수 있는 형태가 아닙니다.

```python
# main.py
def greet(name):
    print(f"안녕하세요, {name}님")

greet("Python")
```

### 소스 코드의 특징

- 들여쓰기로 블록을 구분합니다. 중괄호(`{}`)나 문장 끝 세미콜론(`;`)을 사용하지 않고, 들여쓰기 자체가 문법입니다.
- 진입점이 따로 없습니다. 파일의 첫 줄부터 마지막 줄까지 위에서 아래로 순서대로 실행됩니다.
- 클래스 없이도 실행됩니다. 위 예제처럼 함수나 실행문만으로 하나의 프로그램이 됩니다.
- 타입 선언이 필요 없습니다. 변수에 어떤 값을 넣느냐에 따라 타입이 실행 중에 결정됩니다.

### 실행

`python` 명령어 하나로 변환과 실행이 이어집니다.

```bash
python main.py    # 변환과 실행이 한 번에 처리됨
```

사용자는 변환 과정을 직접 호출하지 않지만, 내부적으로는 소스 코드가 바이트코드로 변환된 뒤 실행됩니다. 이 과정은 다음 섹션에서 다룹니다.

설치와 프로젝트 생성 및 실행은 [개발환경 설정](setup.md)에서 다룹니다.

## 2. 인터프리터의 바이트코드 변환

Python은 문법을 정의한 언어 명세이고, 이를 실제로 실행하는 인터프리터는 여러 종류가 있습니다. 가장 널리 쓰이는 표준 구현체는 C로 작성된 **CPython**이며, 보통 "Python을 설치한다"는 것은 CPython을 설치하는 것을 의미합니다. CPython 인터프리터는 소스 코드를 곧바로 실행하지 않고 먼저 바이트코드로 변환합니다.

| 용어 | 설명 |
|---|---|
| 인터프리터 | 소스 코드를 읽어 실행까지 처리해주는 프로그램 |
| 바이트코드 | 특정 CPU나 운영체제에 종속되지 않는 중간 코드 |

### 변환 과정

인터프리터는 소스 코드를 다음 순서로 바이트코드로 만듭니다.

1. 소스 코드를 읽어 의미 있는 단위(키워드, 이름, 숫자, 문자열 등)로 나눕니다.

    예시: `print("Hello")` 한 줄은 다음과 같이 조각내고 종류를 붙입니다. 이 단계에서는 조각의 배열이 문법에 맞는지 따지지 않고, 끊고 분류하는 일만 합니다.

    | 조각 | 종류 |
    |---|---|
    | `print` | 이름 |
    | `(` | 기호 |
    | `"Hello"` | 문자열 |
    | `)` | 기호 |

2. 나눈 단위가 문법에 맞는지 검사하며 코드의 구조를 만듭니다. 문법에 어긋나면 `SyntaxError`가 발생하고, 실행은 시작되지 않습니다.
3. 구조를 바탕으로 PVM이 실행할 바이트코드를 생성합니다.

이 변환은 프로그램이 실행되기 직전에 매번 자동으로 이루어지므로, 사용자가 별도의 변환 명령을 입력할 필요가 없습니다.

### 바이트코드 확인

변환된 바이트코드는 내장 모듈 `dis`로 사람이 읽을 수 있는 형태로 확인할 수 있습니다.

```bash
python -m dis main.py    # 바이트코드 명령어 목록 출력
```

```text
  0           RESUME                   0

  1           LOAD_NAME                0 (print)
              PUSH_NULL
              LOAD_CONST               0 ('Hello')
              CALL                     1
              POP_TOP
              RETURN_CONST             1 (None)
```

출력되는 `LOAD_NAME`, `CALL`, `RETURN_CONST` 같은 항목이 바이트코드의 명령어이며, PVM은 이 명령어를 순서대로 실행합니다. 명령어의 종류와 이름은 Python 버전에 따라 달라질 수 있습니다.

### 바이트코드 캐시

변환된 바이트코드는 `__pycache__` 폴더에 `.pyc` 파일로 저장됩니다. 소스 코드가 바뀌지 않았다면 다음 실행 때 변환 과정을 생략하고 저장된 파일을 재사용하므로 시작 속도가 빨라집니다.

`.pyc` 파일은 실행 없이 변환만 해서 직접 만들 수도 있습니다.

```bash
python -m py_compile main.py    # __pycache__/main.cpython-312.pyc 생성
```

```text
project/
├── main.py
└── __pycache__/
    └── main.cpython-312.pyc    # 파일명에 인터프리터와 버전이 포함됨
```

- 캐시는 `.pyc` 파일에 기록된 소스 파일의 수정 시간과 현재 소스 파일을 비교해 유효성을 판단합니다. 소스가 수정되었다면 자동으로 다시 변환합니다.
- `python main.py`처럼 직접 실행하기만 하는 파일은 `.pyc`가 저장되지 않고, 다른 파일에서 `import`하는 모듈만 저장됩니다. 위 명령처럼 직접 변환하면 실행 여부와 관계없이 만들어집니다.
- 파일명의 `cpython-312`는 CPython 3.12 버전으로 만들어진 바이트코드라는 뜻이며, 버전이 다르면 별도의 `.pyc` 파일이 만들어집니다.
- `__pycache__`는 삭제해도 다음 실행 때 다시 생성되므로 버전 관리 대상에서 제외합니다.

## 3. PVM의 바이트코드 실행

PVM(Python Virtual Machine)은 바이트코드를 한 줄씩 읽어 각 운영체제에 맞는 명령으로 해석·실행하는 소프트웨어입니다. 프로그램 실행에 필요한 메모리 공간을 마련하고, 더 이상 사용하지 않는 데이터를 자동으로 정리하는 일도 PVM이 담당합니다. CPython에서는 인터프리터의 일부로 포함되어 있어, 변환을 마친 바이트코드가 곧바로 PVM으로 넘어갑니다.

| 용어 | 설명 |
|---|---|
| PVM | 바이트코드의 명령어를 순서대로 해석·실행하는 가상 머신 |
| 스택 | 계산에 필요한 값을 잠시 쌓아두고 꺼내 쓰는 작업 공간 |

### 실행 과정

PVM은 바이트코드의 명령어를 위에서 아래로 하나씩 읽으며, 명령어마다 정해진 동작을 수행합니다. 이 반복은 마지막 명령어에 도달하거나 오류가 발생할 때까지 이어집니다.

1. 다음 명령어를 읽습니다.
2. 명령어에 해당하는 동작(값 불러오기, 함수 호출 등)을 수행합니다.
3. 결과를 스택에 올리거나 저장한 뒤, 다시 1번으로 돌아갑니다.

### 스택 기반 실행

PVM은 값을 스택에 쌓고 꺼내는 방식으로 계산합니다. 앞에서 확인한 `print("Hello")`의 바이트코드는 다음과 같이 실행됩니다.

| 명령어 | 동작 | 스택 상태 |
|---|---|---|
| `LOAD_NAME print` | `print` 함수를 불러와 올립니다. | `print` |
| `PUSH_NULL` | 함수 호출을 준비하기 위해 빈 값을 올립니다. | `print`, `NULL` |
| `LOAD_CONST 'Hello'` | 문자열 `'Hello'`를 올립니다. | `print`, `NULL`, `'Hello'` |
| `CALL 1` | 인자 1개로 함수를 호출하고, 반환값을 올립니다. 이때 화면에 `Hello`가 출력됩니다. | `None` |
| `POP_TOP` | 사용하지 않는 반환값을 버립니다. | (비어 있음) |
| `RETURN_CONST None` | 실행을 마치고 종료합니다. | (비어 있음) |

### 메모리 관리

Python의 모든 값은 객체이며, PVM이 객체를 저장할 메모리를 자동으로 마련합니다. 개발자가 메모리를 직접 할당하거나 해제할 필요가 없습니다.

- 참조 카운팅: 각 객체는 자신을 가리키는 참조의 개수를 기록합니다. 이 개수가 0이 되면 그 객체는 더 이상 쓰이지 않는 것으로 보고 즉시 메모리에서 해제합니다.
- 가비지 컬렉션: 두 객체가 서로를 가리키는 순환 참조는 참조 개수가 0이 되지 않습니다. PVM은 주기적으로 이런 객체를 찾아 함께 정리합니다.

### 실행 중 오류

변환 단계의 문법 오류와 달리, 실행 중에 발생하는 오류는 해당 명령어에 도달했을 때 확인됩니다. 오류가 발생하면 PVM은 실행을 멈추고 오류가 발생한 위치와 종류를 출력합니다.

```python
print("시작")
print(1 / 0)
```

```text
시작
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(1 / 0)
ZeroDivisionError: division by zero
```

- 오류가 발생하기 전의 코드는 이미 실행되므로 `시작`은 정상적으로 출력됩니다.
- 이 오류는 문법이 아니라 실행 시점의 연산에서 발생하므로, 변환 단계에서는 걸러지지 않습니다.
- 오류를 처리하는 방법은 [예외 처리](exception.md)에서 다룹니다.
