# 입력

[← Python으로 돌아가기](index.md)

키보드로 입력받으려면 내장 함수 `input()`을 사용합니다.

---

## 1. 사용

`input()`은 프롬프트 문자열을 출력하고, 사용자가 입력한 값을 항상 `str` 타입으로 반환합니다.

```python
name = input("이름 입력: ")
print(f"안녕, {name}")
```

```
이름 입력: 홍길동
안녕, 홍길동
```

## 2. 숫자 입력

숫자가 필요하면 `int()`나 `float()`로 반환값을 변환합니다.

```python
age = int(input("나이 입력: "))
print(f"내년이면 {age + 1}살")
```

```
나이 입력: 25
내년이면 26살
```
