# 입력

[← Python으로 돌아가기](index.md)

!!! tip "초보자를 위한 안내"
    처음에는 `input()`으로 값을 받는 방법과, 입력값은 항상 문자열이라서 숫자로 계산하려면 `int()`로 변환해야 한다는 점만 익히면 충분합니다. 반복 입력과 한 줄에 여러 값을 받는 방법은 이런 것이 있다는 정도만 훑어보고, 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

입력은 프로그램이 실행 중에 사용자로부터 값을 받는 것이며, 이 문서에서는 `input()`으로 값을 받는 방법, 숫자로 변환해 입력받는 방법, 변환 실패 시의 동작, 반복 입력과 여러 값 입력을 다룹니다.

---

## 1. 입력이란

프로그램은 코드에 적힌 값만으로 동작할 수도 있지만, 실행 중에 사용자가 키보드로 값을 넣게 할 수도 있습니다. Python에서는 내장 함수 `input()`을 호출하면 프로그램이 멈추고, 사용자가 입력 후 Enter를 누르면 그 값을 반환합니다.

```python
name = input("이름 입력: ")
print(f"안녕, {name}")
```

```text
이름 입력: 홍길동
안녕, 홍길동
```

| 용어 | 설명 |
|---|---|
| 입력 | 실행 중에 사용자로부터 값을 받는 것 |
| 프롬프트 | `input()`의 괄호 안에 적어 입력 전에 보여주는 안내 문자열 |
| 반환값 | 함수가 실행을 마치고 돌려주는 값 (`input()`은 입력한 문자열) |

- 프롬프트는 생략할 수 있으며, 생략하면 안내 문구 없이 입력만 기다립니다.
- 사용자가 입력하는 `홍길동`은 출력이 아니라 입력이며, Enter를 누를 때까지 프로그램은 다음 줄로 넘어가지 않습니다.
- 값을 출력하는 방법은 [출력](output.md)에서 자세히 다룹니다.
- 반환값을 변수에 대입하는 방법은 [변수](variable.md)에서 자세히 다룹니다.

### 입력값의 형태

`input()`은 사용자가 입력한 내용을 그대로 문자열로 반환하며, 줄 바꿈(Enter)만 제외됩니다.

```python
name = input("이름 입력: ")
print(f"[{name}]", len(name))
```

```text
이름 입력:   홍 길동  
[  홍 길동  ] 8
```

- 앞뒤와 중간의 공백도 입력값에 그대로 포함됩니다.
- 공백을 없애려면 문자열 메서드 `strip()`을 사용하며, [문자열](string.md)에서 자세히 다룹니다.

### 아무것도 입력하지 않은 경우

Enter만 누르면 오류가 아니라 빈 문자열(`""`)이 반환됩니다.

```python
name = input("이름 입력: ")
print(f"[{name}]", len(name))
```

```text
이름 입력: 
[] 0
```

- 입력이 없어도 프로그램은 계속 진행되므로, 빈 값이 들어올 수 있다는 점을 염두에 둡니다.

---

## 2. 숫자 입력

`input()`은 `25`를 입력해도 숫자가 아니라 문자열 `"25"`를 반환합니다. 숫자로 계산하려면 `int()`나 `float()`로 반환값을 변환해야 합니다.

| 형태 | 의미 |
|---|---|
| `int(input(...))` | 입력받은 문자열을 정수로 변환합니다. |
| `float(input(...))` | 입력받은 문자열을 실수로 변환합니다. |

```python
age = int(input("나이 입력: "))
print(f"내년이면 {age + 1}살")
```

```text
나이 입력: 25
내년이면 26살
```

| 용어 | 설명 |
|---|---|
| 중첩 호출 | 함수 호출의 결과를 바로 다른 함수의 인수로 넘기는 것 (`int(input(...))`) |

- 안쪽의 `input()`이 먼저 실행되어 문자열을 반환하고, 바깥의 `int()`가 그 문자열을 정수로 바꿉니다.
- 변환하지 않고 더하면 `"25" + 1`이 되어 `TypeError`가 발생합니다.
- 변환 방법은 [형변환](casting.md)에서 자세히 다룹니다.

### 변환하지 않은 경우

변환하지 않고 두 입력값을 `+`로 연결하면 숫자 덧셈이 아니라 문자열 이어 붙이기가 됩니다.

```python
a = input("첫 번째 수: ")
b = input("두 번째 수: ")

print(a + b)
print(int(a) + int(b))
```

```text
첫 번째 수: 10
두 번째 수: 20
1020
30
```

- `a`와 `b`는 문자열이므로 `"10" + "20"`은 `"1020"`입니다.
- 계산에 사용할 값은 입력받는 시점에 바로 변환해 두는 편이 안전합니다.

### 실수 입력

소수가 들어올 수 있는 값은 `float()`로 변환합니다.

```python
price = float(input("가격 입력: "))
print(price * 2)
```

```text
가격 입력: 1500
3000.0
```

- 정수 형태(`1500`)로 입력해도 `float()`로 변환하면 결과는 `float`입니다.
- 정수만 받을 값은 `int()`, 소수가 가능한 값은 `float()`를 사용합니다.

## 3. 입력 오류

숫자로 변환할 수 없는 값을 입력하면 `ValueError`가 발생하고 프로그램이 종료됩니다.

```python
age = int(input("나이 입력: "))
```

```text
나이 입력: abc
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    age = int(input("나이 입력: "))
ValueError: invalid literal for int() with base 10: 'abc'
```

| 용어 | 설명 |
|---|---|
| `ValueError` | 타입은 맞지만 값이 올바르지 않을 때 발생하는 오류 |

- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
- 잘못된 입력을 처리해 프로그램이 종료되지 않게 하는 방법은 [예외 처리](exception.md)에서 자세히 다룹니다.

### 변환 실패하는 입력

`int()`로 변환할 수 없는 입력은 다음과 같습니다.

| 입력 | 결과 | 비고 |
|---|---|---|
| `abc` | `ValueError` | 숫자 형태가 아닌 문자열 |
| `3.14` | `ValueError` | 소수 형태의 문자열 |
| (빈 입력) | `ValueError` | 빈 문자열도 숫자가 아님 |
| ` 25 ` | `25` | 앞뒤 공백은 허용됨 |

```python
age = int(input("나이 입력: "))
```

```text
나이 입력: 3.14
Traceback (most recent call last):
  File "main.py", line 1, in <module>
    age = int(input("나이 입력: "))
ValueError: invalid literal for int() with base 10: '3.14'
```

- 소수가 입력될 수 있다면 `int()`가 아니라 `float()`를 사용합니다.
- 앞뒤 공백은 변환 시 무시되지만, 숫자 사이의 공백(`"1 2"`)은 변환되지 않습니다.
- `float()`도 같은 규칙이며, 변환 실패의 종류는 [형변환](casting.md)에서 자세히 다룹니다.

## 4. 반복 입력과 여러 값 입력

### 반복해서 입력받기

`input()`을 반복문 안에서 호출하면 종료 조건이 나올 때까지 계속 입력받을 수 있습니다.

```python
total = 0

while True:
    text = input("숫자 입력 (종료: q): ")
    if text == "q":
        break
    total += int(text)

print(f"합계: {total}")
```

```text
숫자 입력 (종료: q): 10
숫자 입력 (종료: q): 20
숫자 입력 (종료: q): q
합계: 30
```

- 입력값을 숫자로 변환하기 전에 `"q"`인지 먼저 확인해야 합니다. 변환부터 하면 `q`에서 `ValueError`가 발생합니다.
- `while`과 `break`는 [반복문](loop.md)에서, `if`는 [조건문](conditional.md)에서 자세히 다룹니다.

### 한 줄에 여러 값 입력받기

한 줄에 공백으로 구분해 입력받은 문자열은 `split()`으로 나눈 뒤 각각 변수에 대입할 수 있습니다.

```python
x, y = input("두 수 입력: ").split()

print(int(x) + int(y))
```

```text
두 수 입력: 3 4
7
```

- `split()`의 결과는 모두 문자열이므로, 숫자로 계산하려면 각각 변환해야 합니다.
- 입력한 값의 개수가 변수의 개수와 다르면 `ValueError`가 발생합니다. 예를 들어 `3`만 입력하면 `not enough values to unpack (expected 2, got 1)`이 표시됩니다.
- `split()`은 [문자열](string.md)에서, 여러 변수에 한 번에 대입하는 방법은 [변수](variable.md)에서 자세히 다룹니다.
