# 프로그램 구조

[← Python으로 돌아가기](index.md)

Python 프로그램은 `.py` 파일에 작성한 코드를 위에서 아래로 순서대로 실행하는 구조이며, 이 문서에서는 첫 프로그램을 통해 실행 방식과 코드를 구성하는 기본 규칙을 다룹니다.

---

## 1. 첫 프로그램

가장 간단한 Python 프로그램은 `print()` 한 줄입니다. 별도의 클래스나 `main` 함수 없이도 하나의 프로그램이 됩니다.

```python
# hello.py
print("Hello, World!")
```

터미널에서 `python` 명령어 뒤에 파일명을 입력하면 실행됩니다.

```bash
python hello.py
```

```text
Hello, World!
```

| 용어 | 설명 |
|---|---|
| 스크립트 | 위에서 아래로 순서대로 실행되는 Python 파일 |

설치와 프로젝트 생성 및 실행은 [개발환경 설정](setup.md)에서 다룹니다.

## 2. 실행 순서

Python은 진입점이 따로 없으며, 파일의 첫 줄부터 마지막 줄까지 한 줄씩 순서대로 실행합니다.

```python
print("1번")
print("2번")
print("3번")
```

```text
1번
2번
3번
```

- 코드의 순서가 곧 실행 순서입니다.
- 실행 중 오류가 발생하면 그 줄에서 멈추고, 이후 코드는 실행되지 않습니다.

## 3. 주석

`#` 뒤에 오는 내용은 실행되지 않으며, 코드에 대한 설명을 남길 때 사용합니다.

```python
# 한 줄 주석
print("Hello")  # 코드 뒤에도 작성할 수 있습니다
```

```text
Hello
```

- 주석은 해당 줄의 끝까지만 적용됩니다.
- 여러 줄 주석 문법은 따로 없으며, 줄마다 `#`을 붙입니다.

## 4. 들여쓰기

Python은 중괄호(`{}`) 대신 들여쓰기로 코드 블록을 구분합니다. 같은 블록 안의 코드는 들여쓰기 칸 수가 같아야 합니다.

```python
if True:
    print("블록 안")
    print("같은 블록")
print("블록 밖")
```

```text
블록 안
같은 블록
블록 밖
```

- 들여쓰기는 공백 4칸을 사용하는 것이 관례입니다.
- 들여쓰기가 맞지 않으면 `IndentationError`가 발생하고, 실행은 시작되지 않습니다.
- `if` 문법은 [조건문](conditional.md)에서 다룹니다.

## 5. 문장과 줄

Python은 한 줄에 하나의 문장을 작성하는 것이 기본입니다.

```python
print("첫 번째 문장입니다.")
print("두 번째 문장입니다.")
```

```text
첫 번째 문장입니다.
두 번째 문장입니다.
```

### 줄 이어쓰기

문장이 길면 괄호 안에서는 줄을 바꿔도 하나의 문장으로 처리됩니다.

```python
total = (1 + 2
         + 3 + 4)
print(total)
```

```text
10
```

괄호 밖에서 줄을 이으려면 줄 끝에 역슬래시(`\`)를 붙입니다.

```python
total = 1 + 2 \
        + 3 + 4
print(total)
```

```text
10
```

값을 화면에 출력하는 방법은 [출력](output.md)에서 다룹니다.
