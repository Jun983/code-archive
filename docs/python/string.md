# 문자열

[← Python으로 돌아가기](index.md)

!!! tip "초보자를 위한 안내"
    처음에는 따옴표로 문자열을 만드는 방법, `len()`과 인덱싱, 그리고 `f"{변수}"` 형태의 f-string만 익히면 충분합니다. 메서드와 raw string은 이런 것이 있다는 정도만 훑어보고, 필요할 때 다시 찾아보거나 다른 문서를 학습한 뒤에 다시 읽으면 훨씬 쉽게 이해됩니다.

문자열(`str`)은 문자의 나열을 나타내는 타입이며, 이 문서에서는 문자열을 만드는 방법과 인덱싱·슬라이싱, 주요 메서드, 이스케이프를 해석하지 않는 raw string, 값을 끼워 넣는 f-string을 다룹니다.

---

## 1. 선언

문자열은 작은따옴표(`'`) 또는 큰따옴표(`"`)로 감싸 만들며, 삼중따옴표(`"""`)를 사용하면 여러 줄을 표현할 수 있습니다.

```python
name = "홍길동"
greeting = '안녕하세요'
empty = ""
multiline = """여러 줄
문자열"""

print(name)
print(greeting)
print(multiline)
```

```text
홍길동
안녕하세요
여러 줄
문자열
```

| 용어 | 설명 |
|---|---|
| 빈 문자열 | 문자가 하나도 없는 문자열 (`""`) |
| 삼중따옴표 | 줄 바꿈을 그대로 포함할 수 있는 문자열 표기 (`"""`) |

- 작은따옴표와 큰따옴표는 동일하게 동작하며, 한 종류를 일관되게 사용합니다.
- 숫자를 따옴표로 감싸면(`"10"`) 숫자가 아니라 문자열입니다. 타입은 [타입](type.md)에서 자세히 다룹니다.

### 따옴표가 들어간 문자열

문자열 안에 따옴표를 넣으려면 감싸는 따옴표와 다른 종류를 사용합니다.

```python
print("It's me")
print('He said "hi"')
```

```text
It's me
He said "hi"
```

- 같은 종류의 따옴표를 넣으려면 앞에 역슬래시를 붙이는 이스케이프를 사용하며, [출력](output.md)에서 자세히 다룹니다.

### 변경 불가

문자열은 한 번 만들면 내용을 바꿀 수 없습니다. 일부 문자를 바꾸려고 하면 `TypeError`가 발생합니다.

```python
word = "Hello"
word[0] = "h"
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    word[0] = "h"
TypeError: 'str' object does not support item assignment
```

- 변경이 필요하면 새 문자열을 만들어 변수에 다시 대입합니다.
- 오류 메시지의 세부 표시는 Python 버전에 따라 다를 수 있습니다.
- 변수에 값을 다시 대입하는 방법은 [변수](variable.md)에서 자세히 다룹니다.
- 문자열을 `+`로 이어 붙이거나 `*`로 반복하는 방법은 [연산자](operator.md)에서 자세히 다룹니다.

## 2. 길이와 인덱싱

`len()`은 문자열의 길이를 반환하는 내장 함수입니다. 대괄호(`[]`)로 특정 위치의 문자나 일부 구간을 가져올 수 있으며, 위치를 나타내는 번호(인덱스)는 0부터 시작합니다.

```python
word = "Hello"

print(len(word))
print(word[0])
print(word[-1])
print(word[1:3])
```

```text
5
H
o
el
```

| 용어 | 설명 |
|---|---|
| 인덱스 | 문자열에서 문자의 위치를 나타내는 번호 (0부터 시작) |
| 슬라이싱 | `s[start:end]`로 `start`부터 `end` 직전까지의 부분 문자열을 가져오는 것 |

- 음수 인덱스는 뒤에서부터 센 위치이며, `-1`이 마지막 문자입니다.
- 범위를 벗어난 인덱스를 지정하면 `IndexError`가 발생합니다.
- 공백, 한글도 문자 하나로 세므로 `len("안녕")`은 `2`, `len("a b")`는 `3`입니다.

### 인덱스 범위

`Hello`의 각 문자와 인덱스는 다음과 같습니다.

| 문자 | `H` | `e` | `l` | `l` | `o` |
|---|---|---|---|---|---|
| 인덱스 | 0 | 1 | 2 | 3 | 4 |
| 음수 인덱스 | -5 | -4 | -3 | -2 | -1 |

- 길이가 `n`인 문자열의 유효한 인덱스는 `0`부터 `n - 1`까지입니다.

```python
word = "Hello"
print(word[5])
```

```text
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(word[5])
IndexError: string index out of range
```

### 슬라이싱 생략

`start`나 `end`를 생략하면 처음부터, 또는 끝까지로 처리합니다. `[start:end:step]`처럼 세 번째 값으로 건너뛰는 간격을 지정할 수도 있습니다.

```python
word = "Hello"

print(word[:3])
print(word[2:])
print(word[::2])
print(word[::-1])
print(word[1:100])
```

```text
Hel
llo
Hlo
olleH
ello
```

- `[:3]`은 처음부터 3번째 직전까지, `[2:]`는 2번 인덱스부터 끝까지입니다.
- `step`이 음수이면 뒤에서부터 읽으므로, `[::-1]`은 문자열을 뒤집습니다.
- 슬라이싱은 범위를 벗어나도 오류 없이 가능한 부분만 가져옵니다. 인덱싱과 달리 `IndexError`가 발생하지 않습니다.

## 3. 주요 메서드

메서드는 값에 속한 함수이며, `변수명.메서드명()` 형태로 호출합니다. 문자열 메서드는 원본을 바꾸지 않고 새 문자열을 반환합니다.

| 메서드 | 반환 타입 | 설명 |
|---|---|---|
| `upper()` | `str` | 모든 문자를 대문자로 변환합니다. |
| `lower()` | `str` | 모든 문자를 소문자로 변환합니다. |
| `strip()` | `str` | 문자열 양 끝의 공백을 제거합니다. |
| `split(sep)` | `list` | 구분자를 기준으로 문자열을 나눕니다. |

```python
word = "Hello"

print(word.upper())
print(word.lower())
print("  hi  ".strip())
print("a,b,c".split(","))
print(word)
```

```text
HELLO
hello
hi
['a', 'b', 'c']
Hello
```

- 마지막 줄처럼 메서드를 호출해도 원본 `word`는 그대로이며, 결과를 쓰려면 변수에 대입하거나 바로 출력합니다.
- `split()`의 결과인 `list`는 [자료구조](data-structures.md)에서 자세히 다룹니다.
- 메서드와 함수의 차이는 [함수](function.md)에서 자세히 다룹니다.

### 검색과 치환

문자열에 특정 내용이 있는지 확인하거나 일부를 바꿀 때 사용하는 메서드입니다.

| 메서드 | 반환 타입 | 설명 |
|---|---|---|
| `replace(old, new)` | `str` | `old`를 모두 `new`로 바꿉니다. |
| `find(sub)` | `int` | `sub`가 처음 나오는 인덱스를 반환하며, 없으면 `-1`입니다. |
| `count(sub)` | `int` | `sub`가 나오는 횟수를 반환합니다. |
| `startswith(sub)` | `bool` | `sub`로 시작하는지 확인합니다. |
| `endswith(sub)` | `bool` | `sub`로 끝나는지 확인합니다. |

```python
text = "hello world"

print(text.replace("l", "L"))
print(text.find("o"))
print(text.find("z"))
print(text.count("l"))
print(text.startswith("he"))
print(text.endswith("ld"))
```

```text
heLLo worLd
4
-1
3
True
True
```

- `find()`는 없는 경우에도 오류가 아니라 `-1`을 반환합니다. `0`도 유효한 인덱스이므로, 결과가 `-1`인지로 존재 여부를 판단합니다.
- 단순히 포함 여부만 확인할 때 쓰는 `in`은 [연산자](operator.md)에서 자세히 다룹니다.

### 분리와 결합

`split()`은 문자열을 나누고, `join()`은 여러 문자열을 하나로 합칩니다.

```python
print("a b  c".split())
print("a,b,c".split(","))
print("-".join(["a", "b", "c"]))
```

```text
['a', 'b', 'c']
['a', 'b', 'c']
a-b-c
```

- 인수 없이 `split()`을 호출하면 공백을 기준으로 나누며, 연속된 공백도 하나로 처리합니다.
- `join()`은 구분자 문자열에서 호출하며, 합칠 문자열을 `list`로 전달합니다.
- `strip()`은 양 끝만 제거하며, 한쪽만 제거하려면 `lstrip()`(왼쪽)과 `rstrip()`(오른쪽)을 사용합니다.

## 4. raw string

문자열 앞에 `r`을 붙이면 역슬래시(`\`)를 특수 문자로 해석하지 않고 그대로 사용합니다. 역슬래시가 많은 파일 경로를 표현할 때 유용합니다.

```python
print("C:\\new\\folder")
print(r"C:\new\folder")
```

```text
C:\new\folder
C:\new\folder
```

| 용어 | 설명 |
|---|---|
| raw string | 앞에 `r`을 붙여 이스케이프 문자를 해석하지 않는 문자열 |

- 일반 문자열에서는 `\n`이 줄 바꿈으로 해석되지만, raw string에서는 `\`와 `n` 두 글자 그대로 유지됩니다.
- 역슬래시 하나로 끝나는 문자열(`r"C:\"`)은 만들 수 없습니다.
- 이스케이프 문자는 [출력](output.md)에서 자세히 다룹니다.

### 일반 문자열과의 차이

`\n`이 포함된 문자열을 일반 문자열과 raw string으로 출력하면 결과가 다릅니다.

```python
print("a\nb")
print(r"a\nb")
```

```text
a
b
a\nb
```

- 일반 문자열은 `\n`을 줄 바꿈으로 해석하므로 두 줄로 출력됩니다.
- raw string은 `\n`을 두 글자 그대로 유지하므로 한 줄로 출력됩니다.
- 경로를 일반 문자열로 쓸 때 `\n`, `\t` 같은 조합이 우연히 포함되면 의도와 다르게 해석됩니다.

## 5. f-string

문자열 앞에 `f`를 붙이면 `{}` 안에 변수나 표현식을 바로 삽입할 수 있습니다.

```python
name = "지수"
age = 25

print(f"{name}님은 {age}살입니다.")
print(f"내년이면 {age + 1}살")
```

```text
지수님은 25살입니다.
내년이면 26살
```

| 용어 | 설명 |
|---|---|
| f-string | 앞에 `f`를 붙여 `{}` 안의 값을 문자열에 끼워 넣는 문자열 |

- `{}` 안에는 변수뿐 아니라 계산식도 쓸 수 있으며, 결과가 문자열로 변환되어 삽입됩니다.
- `f`를 빼먹으면 `{}`가 치환되지 않고 그대로 출력됩니다.

### 서식 지정

`{}` 안에서 `:` 뒤에 서식을 적으면 값이 표시되는 모양을 정할 수 있습니다.

```python
price = 1234567.891
pi = 3.14159

print(f"{pi:.2f}")
print(f"{price:,}")
print(f"{price:,.1f}")
print(f"{5:03d}")
print(f"{'x':>5}|")
```

```text
3.14
1,234,567.891
1,234,567.9
005
    x|
```

| 서식 | 설명 |
|---|---|
| `:.2f` | 소수점 아래 2자리까지 표시 (반올림) |
| `:,` | 천 단위마다 쉼표 표시 |
| `:03d` | 3자리 정수로 표시하고, 빈자리는 `0`으로 채움 |
| `:>5` | 5칸 너비에서 오른쪽 정렬 |

- 서식은 표시 모양만 바꾸며, 변수에 저장된 값은 그대로입니다.
- 서식 문법은 종류가 많으므로 필요할 때 찾아서 사용합니다.

### 중괄호 출력

문자열에 `{`, `}` 자체를 넣으려면 두 번 연달아 씁니다.

```python
print(f"{{중괄호}}")
```

```text
{중괄호}
```

- 값을 화면에 출력하는 `print()`의 기본 사용법은 [출력](output.md)에서 자세히 다룹니다.
